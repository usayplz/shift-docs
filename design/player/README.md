# Плеер практики: нижняя панель и лист «Настройки» (вариант 1b)

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`). Меняется нижняя панель плеера, добавляется лист «Настройки» с параметром практики. Шапка, орб, фон, «Приготовься» и «Как теперь?» — без изменений. Звука дыхания в приложении нет (удалён ранее; если код ещё остался — удалить: ключ `breath`, `playBreath`/`stopBreath`, ассет `sounds/breath-615047.mp3`).

HTML-файлы — **референс дизайна**, не код для переноса. Fidelity — **hi-fi**.

## Макет нижней панели (сверху вниз)

`Column`, по центру, gap 12 dp, по бокам 20 dp, снизу nav bar inset + 30 dp.

1. **Следующая фаза** — 14 sp, 800, цвет `deep` цели, высота 20 dp.
2. **Прогресс** — сегменты 4 dp, r 2, gap 4; под ним «0:42» / «−2:18», 13 sp, 700, `body2`, tabular.
3. **Ряд** — `Row(Arrangement.SpaceEvenly)`:
   - **Голос**: круг 52 dp. Вкл. — фон `pill`, иконка `microphone` `ink`. Выкл. — прозрачный фон, обводка 1.5 dp `dash`, иконка `microphone-slash` `muted`. Тап переключает сразу, без паузы; при выключении оборвать текущую фразу TTS.
   - **Пауза / Продолжить**: круг 68 dp, `#FFFFFF`, тень `0 14 30 −10 rgba(40,45,90,.35)`, иконка fill `pause` / `play` 28 dp, `deep`.

4. **Ссылка** «Закончить и оценить» (в пробном запуске — «Вернуться в редактор»), высота 28 dp.

## Лист «Настройки»

`ModalBottomSheet`, фон `background`, верхние углы 28 dp, отступы 20 / 30 dp, gap 18 dp. Скрим `rgba(30,30,50,.36)`.

1. Хэндл 40×5 dp, `outline`.
2. Заголовок «Настройки» — Nunito 800, 22 sp.
3. **Параметр практики** (только если у практики есть `tune` и она запущена одна, не шагом составной):
   - капс-заголовок `tune.label` («ДЛИТЕЛЬНОСТЬ ФАЗЫ», «ТЕМП»…);
   - карточка `card`, r 20, padding 14/16, gap 12: слева число «5 с» (Nunito 800 28 sp + «с» 15 sp `muted`), справа чип «рек. 4 с» (обводка `outline`) / «✓ рекомендуем» (фон `subtle`) — тап ставит рекомендованное; слайдер как у длительности (трек 10 dp `subtle`, заливка `color` цели, бегунок 26 dp, тонкая отметка рекомендованного 2×14 dp `deep` 35%); подписи min / max 12 sp `muted`; для резонансного — «≈ 5,5 циклов в минуту» 13.5 sp `muted`;
   - под карточкой — «Применится со следующего круга», 13.5 sp `muted`.
4. **Ведение** — капс-заголовок, карточка `card` r 20 с тремя строками 52 dp (разделитель `divider`): иконка 20 dp · название · `Switch`. Голос (`microphone`), Тон смены фазы (`bell`), Вибро (`vibrate`). Те же ключи настроек, что в «Настройках» приложения и кнопке «Голос».
5. Кнопка «Продолжить» — главная, 56 dp.

## Поведение

- Тап по «Настройки»: запомнить `wasRunning = running`, поставить паузу, открыть лист.
- Закрытие листа (кнопка, тап по скриму, свайп вниз): если параметр менялся — пересобрать план (см. ниже); затем `running = wasRunning`.
- Пересборка: паттерн = `tune.target` применённый к `tech` практики (`ALL_PHASES` — все фазы = v; `OUT` — только выдох = v); `buildPlan` на те же минуты; `elapsed = floor(elapsed / cycle) * cycle` (начало текущего круга в новом паттерне); если `elapsed < 0` («Приготовься») — не трогать.
- Значение сохраняется в `Prefs.tuneMemory[practiceId]` и используется при следующих запусках.
- Тап по пустому месту экрана — пауза / продолжить. Тапы внутри листа и по кнопкам ряда паузу не переключают.
- Переключатели в листе срабатывают сразу.

Параметры практик — `spec.md` §5.4.1 (box, reson, exhale, sighs). У остальных в листе только «Ведение».

## Доступность

- Голос: `Role.Switch`, contentDescription «Ведение голосом», `stateDescription` «вкл.» / «выкл.».
- Настройки: `Role.Button`, «Настройки практики». Пауза: «Пауза» / «Продолжить».
- Слайдер параметра: `progressBarRangeInfo` с шагом, озвучивание «5 секунд».
- Зона нажатия ≥ 44 dp; ширина 320 dp; fontScale 2 — лист прокручивается.

## Проверить

- [ ] В ряду три кнопки: Голос, ⏸, Настройки; промежутки одинаковые.
- [ ] Голос выкл. — перечёркнутый микрофон и обводка; TTS замолкает сразу.
- [ ] Настройки ставят паузу; «Продолжить» снимает её, только если практика шла.
- [ ] Квадратное: 3–7 с, рек. 4. Резонансное: 4,5–6,5 с шаг 0,5, рек. 5, подпись «≈ N циклов в минуту». Удлинённый выдох: 6–10. Циклические вздохи: 4–8.
- [ ] После изменения текущий круг начинается заново в новом темпе; оставшееся время пересчитано.
- [ ] Значение запоминается для практики и применяется при следующем запуске.
- [ ] В шаге составной практики и у практик без параметра — только «Ведение».
- [ ] На паузе в орбе последнее значение, не слово «Пауза».
- [ ] «Заново» нигде нет.
- [ ] Светлая / тёмная тема, все цвета целей, 320 dp, fontScale 2, TalkBack.
