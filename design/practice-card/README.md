# Карточка практики: лента разделов и компактный низ (варианты 1b + 1d)

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`). Переделывается состояние «A. Карточка практики» экрана сессии. Плеер и «Как теперь?» — отдельно (`player/README.md`).

HTML-файлы — **референс дизайна**, не код для переноса. Fidelity — **hi-fi**.

## Источник истины

- `prototype/Shift v10 Android.dc.html` → любая практика из Каталога. Логика: `pinfo` (`eff`, `how`, `hasMore`, `descMax`), `pdur`, `dsh`, `dScroll`, `cust`, константа `EFF`.
- `prototype/Карточка практики - варианты.dc.html` → **#1b** (лента + компактный низ) и **#1d** (сворачивающаяся шапка) — выбраны вместе; экран «Тап на „3 мин“» — лист длительности. 1a и 1c отклонены.
- `spec.md` §3.4 A, §5.8. При расхождении верен прототип.

## Что меняется

| Было | Стало |
|---|---|
| Разделы «Почему работает» и «Противопоказания» | Лента: **Описание · Эффекты · Противопоказания · Как выполнять** |
| Внизу карточка длительности со слайдером (~140 dp) | Пилюля «N мин ↕» + «Начать» в одну строку (56 dp); слайдер — в листе |

| Название только в ленте | При прокрутке > 64 dp название появляется в верхней панели |

## Макет

Экран: фон — градиент `softer` цели → `background` (70%). Верхняя панель 44 dp: «Назад» слева, название по центру (Nunito 800, 17 sp, одна строка с многоточием; видно только после прокрутки, плавно 200 мс).

**Лента** (`LazyColumn`, по бокам 20 dp, снизу отступ под закреплённый низ 100 dp):

1. Капс «НАПРАВЛЕНИЕ · ЦЕЛЬ» (`deep` цели) · название Nunito 800 26 sp · справа `Row(gap 8)`: ♥ (`heart` / fill `heart` `#E86A6A`) и `sliders-horizontal` (только у дыхательных) — круги 44 dp фон `card`. Ниже 18 dp.
2. **ОПИСАНИЕ** — `line` Nunito 800 18 sp; `why` 15 sp / 1.55 `body2`. Если `why` > 115 символов: `maxLines = 3` и пилюля «Подробнее ⌄» (34 dp, фон `card`, 13.5 sp 800 `accentText`) → раскрывает на месте, текст «Свернуть ⌃».
3. **ЭФФЕКТЫ** — 2–3 строки: иконка `check` bold 13 dp `deep` + текст 15 sp `body2`, gap 6. Скрыть раздел, если пусто.
4. **ПРОТИВОПОКАЗАНИЯ** — точки 5 dp `muted` + текст; «Особых ограничений нет», если пусто; всегда последней строкой `muted`: «Если станет некомфортно — остановись и дыши как обычно».
5. **КАК ВЫПОЛНЯТЬ** — нумерованный список, gap 12: круг 24 dp фон `card`, цифра 12 sp 800 `deep`; текст 15 sp / 1.5. Дыхательные — фазы паттерна «Вдох — 4 с», «Задержка — 4 с»… (задержка после выдоха тоже «Задержка»); остальные — `steps`.

Заголовки разделов — `labelSmall` капс, `label`; отступ перед разделом 14 dp.

**Низ** (закреплён, 20 dp по бокам, nav inset + 30 dp): `Row(gap 10)`:
- пилюля 56 dp, r 30, фон `card`: «3» Nunito 800 20 sp, «мин» 14 sp `muted`, `caret-up-down` bold 14 dp `muted`. Если min = max — без иконки, не нажимается;
- «Начать» — главная кнопка 56 dp, `weight(1f)`.

**Лист «Длительность»** (`ModalBottomSheet`, фон `background`, r 28 сверху, gap 16): хэндл · «Длительность» 22 sp + ✕ 44 dp · текущая карточка длительности (число минут, чип «рек.», слайдер min..max с подписями) · «Начать · N мин». Закрытие — тап мимо, ✕, свайп; значение сохраняется в `durMemory`.

## Данные

- `Practice.effects: List<String>` — новое поле. Тексты для 18 практик — константа `EFF` в прототипе; **черновые, вычитать**.
- «Как выполнять» строится из `tech` или `steps`, отдельного поля не нужно.
- При открытии карточки: лента наверху, «Подробнее» свёрнуто, лист закрыт.

## Проверить

- [ ] Порядок разделов: Описание, Эффекты, Противопоказания, Как выполнять.
- [ ] «Подробнее» есть только у длинных описаний; раскрывает и сворачивает.
- [ ] Прокрутка > 64 dp — название в верхней панели; обратно — исчезает.
- [ ] ♥ меняет избранное сразу; настройка видна только у дыхательных.
- [ ] Пилюля открывает лист; «Начать · N мин» из листа запускает практику.
- [ ] Практика с min = max — пилюля без ↕ и не нажимается.
- [ ] Светлая / тёмная тема, все цели, 320 dp, fontScale 2, TalkBack (разделы — `heading()`).
