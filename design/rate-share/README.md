# Настройки: «Оценить Shift» и «Поделиться приложением»

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`, платформенные вызовы через `expect/actual`). В Настройках, в блоке «О приложении», появляются две строки. Своих экранов и листов нет — обе строки открывают системные окна.

HTML — **референс дизайна**, не код для переноса. Fidelity — **hi-fi**.

## Источник истины

- `prototype/Shift v10 Android.dc.html` → нижнее меню «Настройки» → блок «О приложении». Разметка — кнопки с `doc.rate` и `doc.share`; логика — `docVals()` (`rate`, `share`, `shareIc`). В прототипе нажатие показывает только подсказку «Откроется…» — это заглушка, в приложении подсказки нет.
- `rate-share/screens/01-settings-about.png` — блок «О приложении», 2× (ширина экрана 370 dp).
- Если прототип и этот файл расходятся, верен прототип.

## Макет

Блок «О приложении» — та же карточка (`card`, r 22, отступы 4 / 16 dp). Порядок строк:

1. **Оценить Shift** — новая
2. **Поделиться приложением** — новая
3. Политика конфиденциальности
4. Условия подписки
5. Написать в поддержку
6. Версия

Новые строки — как «Написать в поддержку»: высота по содержимому, отступы 14 dp сверху и снизу, текст 15 sp 700 `ink` слева, иконка 18 dp `muted` справа, разделитель 1 dp `divider` снизу.

| Строка | Иконка (Phosphor regular) |
|---|---|
| Оценить Shift | `star` |
| Поделиться приложением | Android — `share-network`, iOS — `export` |

Стрелки `caret-right` у этих строк нет: они не ведут на экран приложения.

## Поведение

**Оценить Shift** — открывает страницу приложения в магазине, сразу на оценке:
- Android: `market://details?id=<applicationId>`; если Google Play недоступен — `https://play.google.com/store/apps/details?id=<applicationId>` в браузере.
- iOS: `https://apps.apple.com/app/id<APP_ID>?action=write-review`.
- Системное окно оценки внутри приложения (In-App Review / `SKStoreReviewController`) здесь **не использовать**: система может его не показать, и нажатие ничего не сделает.

**Поделиться приложением** — системное окно «Поделиться» (Android Sharesheet / `UIActivityViewController`) с текстом:

> Shift — короткие практики, чтобы сменить состояние: дыхание, медитации, таймер. <ссылка>

- Ссылка — на магазин текущей платформы (те же адреса, что выше, без `?action=write-review`).
- iOS, iPad: привязать окно к строке (`popoverPresentationController.sourceView`).

Общее:
- Никаких подтверждений, тостов и своих листов до и после.
- Если открыть магазин или окно не удалось — ничего не показывать, приложение остаётся на Настройках.
- Обе строки доступны всем, подписка не нужна.
- `applicationId` и `APP_ID` — в одном месте (конфиг сборки), не строками в UI.

## Код

```kotlin
// commonMain
interface AppLinks {
  fun openStoreReview()          // «Оценить Shift»
  fun shareApp(text: String)     // «Поделиться приложением»
}
expect fun rememberAppLinks(): AppLinks   // actual: androidMain (Intent), iosMain (UIApplication / UIActivityViewController)
```

- Текст для «Поделиться» — в строковых ресурсах (`share_app_text`), ссылка подставляется параметром.
- `SettingsViewModel` не меняется: строки вызывают `AppLinks` напрямую из экрана.

## Доступность

- `Role.Button`; подписи — текст строки. Иконки декоративные (`contentDescription = null`).
- Зона нажатия — вся строка, высота ≥ 48 dp.
- fontScale 2: текст переносится, иконка остаётся справа по центру строки.
