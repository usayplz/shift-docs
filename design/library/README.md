## 2. Поиск

Отдельного экрана нет. Пока запрос непустой (после `trim`), **всё под полем скрыто** (закладки, чипы, списки) и показаны результаты по всей Библиотеке сразу. Шапка и нижнее меню остаются.

- Результаты обновляются на каждый ввод, без кнопки и задержки. Выбранные закладка и чип на поиск не влияют.
- Запрос живёт, пока открыта Библиотека; переход в практику и назад его сохраняет. Недавних запросов нет.
- Тап по результату — то же, что тап по этому элементу в Библиотеке.

**Как ищем** — только буквальное вхождение подстроки, без морфологии и синонимов.
1. Запрос и текст: нижний регистр, `ё → е`.
2. Запрос делится на слова по пробелам; элемент подходит, если **каждое** слово входит хотя бы в одно поле.
3. Поля:

| Тип | Название | Подзаголовок | Дополнительно |
|---|---|---|---|
| Практика | `title` | строка описания | паттерн / `sub`, направление, названия всех её целей |
| Практика из шагов | название | цепочка шагов | название цели |
| Курс | название | описание | название цели, «курс» |
| Материал | название | описание | тема, «статья» / «видео», «знания» |
| Моя практика | название | паттерн / цепочка | «своя», «дыхание», название её цели |
| Инструмент | «Таймер медитации», «Метроном» | текущие настройки | «инструмент» |

4. Скрытые практики в результаты не попадают.

**Выдача**
- «Найдено: N» — 13 sp, `muted`.
- Группы: **Практики → Курсы → Знания → Мои практики → Инструменты**, пустые не показываются. Внутри: совпадение в названии → в подзаголовке → в остальных полях.
- Подсветка всех вхождений в названии и подзаголовке: фон `#E0D7FC` (тёмная тема — `rgba(174,178,242,.28)`), r 4; цвет текста не меняется.
- Совпала только цель — подзаголовок «Цель: **Сон** · <обычный подзаголовок>», цель подсвечена.

**Ничего не найдено** — по центру, отступ сверху 36 dp, gap 10 dp:
1. орб 88 dp из двух кругов `own` (α .18 и .35) с `magnifying-glass` 24 dp;
2. «По «йога» ничего нет» — Nunito 800, 19 sp;
3. «Ищи по названию, цели или направлению: «сон», «дыхание», «метта»» — 14 sp `muted`, max 260 dp;
4. если запрос входит в название скрытой практики — «Есть в Скрытом: <название>» с `eye-slash`;
5. «Собрать свою практику» — 14 sp 700 `accentText`: очищает поиск, открывает «Моё» с раскрытым меню «Создать практику».

## 6. Цель у своей практики

В обоих редакторах — «дыхательный ритм» (§3.9) и «из нескольких шагов» (§3.8) — **в самом верху, сразу под полем названия**, блок «Цель»:
- заголовок-капс «ЦЕЛЬ» (12 sp 800, трекинг 1, `label`);
- под ним ряд чипов: Фокус, Сон, Спокойствие, Энергия, у каждого слева цветная точка 10 dp (цвет цели);
- чип: высота 40, r 20, отступы 0 / 16, текст 14 sp 800; выбранный — `selBg` / `selFg`, невыбранный — `card` с обводкой 1,5 dp `outline`. Ряд в одну строку, без переноса, с прокруткой до краёв экрана.

Поведение:
- Выбирается **одна** цель: тап по другой переключает, тап по выбранной снимает.
- Блок необязательный. Без цели практика остаётся только в Библиотеке и в подборы не попадает.
- По умолчанию: новый ритм — пусто; практика из шагов — самая частая основная цель её шагов (при равенстве — цель первого шага), пока пользователь не выбрал сам; копия встроенной («Настроить под себя», копия практики из шагов) — основная цель оригинала.
- Времени суток и «действия» в редакторе нет. Слово «теги» в интерфейсе не используем.
- Практики «из аудио» в приложении пока нет; когда появится — тот же блок в том же месте, по умолчанию пусто.

## 7. Единый подбор

Полное правило — `spec.md` §5.3. Коротко:
1. Практика подходит, если выбранная цель есть среди её целей. У своей практики цель одна, у встроенной — одна или две (вторую задаём мы, пользователь её не видит).
2. «На взводе» и «На пределе»: сначала «успокаивает», потом «нейтрально», потом «бодрит».
3. Вечером «бодрит» убираем, если цель не «Энергия».
4. Сначала те, что укладываются в доступное время.
5. Скрытые исключаем; без Plus бесплатные идут первыми.
6. Своя практика встаёт вторым вариантом (первое «Или»), если не хуже стоящей там встроенной; в «На сегодня» — не больше одной своей из трёх.

Первая — главная карточка, следующие две — «Или». Действие своей практики считается из цели: Сон и Спокойствие — успокаивает, Энергия — бодрит, Фокус — нейтрально. Таблица целей и действий встроенных практик — в §5.3. Жёсткие списки id из старой версии §5.3 удалить.

## Что удалить

- «+» в шапке, ленту «Избранное», ленту «Недавние», ленту «Инструменты и мои практики», ленту курсов, группы «Мои практики» и «Инструменты», чип ♥, числа в чипах, «Ещё N…» и сворачивание групп.
- Отдельный экран поиска, если был начат.
- Списки id в `recommend` и набор «На сегодня» по времени суток.
