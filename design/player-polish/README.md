# Плеер дыхания: доработка вида (как у плеера прогулки)

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`). Делает плеер дыхания спокойнее и единым по виду с плеером прогулки (`walk-player/README.md`). Основа — `player/README.md` (вариант 1b): ряд Голос · ⏸ · Настройки, лист «Настройки», орб с кругами и счётом. **Всё из 1b остаётся**, меняется только перечисленное ниже.

HTML — **референс дизайна**, не код для переноса. Fidelity — **hi-fi**.

## Что меняется

| Было | Стало |
|---|---|
| Пауза — белый круг, иконка цветом `deep` | Пауза — **заливка `deep` цели**, иконка белая (в тёмной — цвет фона), **контурная** |
| Под прогрессом «0:42» слева и «−2:18» справа | Только **«−2:18» справа** |
| Название фазы («Вдох», «Задержка», «Выдох») наверху под шапкой | Название фазы **под орбом** |
| Фаза меняется скачком | Короткое растворение и подъём |
| Фон статичный | Фон **«дышит»** вместе с орбом |
| Зона орба: верх 238 dp | Верх **196 dp** (орб чуть выше, чтобы под ним поместилось название фазы) |

Это касается всех практик, которые идут по плану из фаз (дыхательные, раунды, шаги составной практики). Для фаз `guide` (текстовые шаги) и `rest` (свободное дыхание) текст остаётся **наверху**, как сейчас: он бывает длинным. «Приготовься» тоже остаётся наверху, орб на отсчёте — на старом месте (238 dp).

## Макет

**Орб** — без изменений (кольца 330 / 260 / 190 / 120 dp × scale, счёт внутри). Середина зоны орба — **196 + 160 = 356 dp** от верха экрана.

**Название фазы под орбом**
- Верх = середина зоны орба + **172 dp** (ниже самого большого кольца при полном вдохе), по центру, поля 20 dp.
- Nunito 800, 22 sp / 1.25, цвет `deep` цели.
- Анимация смены: первые **300 мс** новой фазы — `alpha 0 → 1` и подъём на 6 dp → 0; последние **180 мс** фазы — `alpha → 0`.
- На паузе текст остаётся видимым (берётся текущая фаза).

**Дышащий фон**
- Поверх фона плеера — белый слой на весь экран, `alpha = k · clamp((scale − 0.55) / 0.45)`, где `scale` — текущий масштаб орба.
- `k = 0.30` в светлой теме, `0.06` в тёмной. На вдохе фон светлеет, на выдохе возвращается.
- Только во время практики (не на «Приготовься», не на карточке и не на «Как теперь?»).

**Нижняя панель** — как в 1b, кроме:
- под прогрессом только оставшееся время справа: «−2:18», 13 sp, 700, `body2`, tabular;
- пауза 68 dp: фон `deep` цели, иконка **контурная** (Phosphor regular, не fill) `pause` / `play` 28 dp — `#FFFFFF` (светлая) / цвет фона (тёмная), тень `0 14 30 −12` цветом `deep` α .6. Голос и Настройки — без изменений (52 dp, фон `pill`).

**«Дальше: …»** — без изменений. В прототипе строка появляется только перед следующим шагом составной практики (за 3,5 с) и в отдыхе между раундами, по фазам дыхания её нет — она и так редкая.

## Код

```kotlin
data class PhaseUi(
  val label: String,          // «Вдох» … ; пусто для guide / rest
  val alpha: Float,           // анимация смены фазы
  val offsetY: Dp,
)
// в PlayerControlsUi из player/README.md
//   - elapsed: String         → удалить из UI (оставить left)
//   + phase: PhaseUi?          → null для guide / rest / «Приготовься»
//   + backgroundLift: Float    → alpha белого слоя
```

- Анимации считать от времени внутри фазы (`elapsed − slot.t0`), а не `animate*AsState`, чтобы на паузе и при пересборке плана (лист «Настройки») всё оставалось согласованным.
- `backgroundLift` брать из того же `scale`, что и орб, без отдельной анимации.
- Цвета — `Shift.colors` и палитра цели; белый слой — `Color.White` с alpha.

## Доступность

- Название фазы — `liveRegion = Polite`, если «Голос» выключен (иначе фазы и так озвучиваются).
- Пауза: `Role.Button`, «Пауза» / «Продолжить». Контраст белой иконки на `deep` всех целей ≥ 3:1 (графический элемент), проверить на «Энергии».
- Reduce motion: без подъёма текста и без дышащего фона, только смена alpha.
- fontScale 2: название фазы не наезжает на прогресс — при нехватке места уменьшить отступ под орбом, но не ниже края самого большого кольца.
