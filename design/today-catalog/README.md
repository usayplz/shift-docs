# «Сегодня» и «Каталог»: новая компоновка, поиск, избранное у инструментов

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`). Каталог становится проще: шапка → поиск → чипы → одна лента инструментов и своих практик → курсы → список практик. Личное («Продолжить», «Избранное») переезжает на «Сегодня». Инструменты (Таймер, Метроном) можно добавлять в избранное.

Это задание **заменяет** `catalog-search/README.md` (поле поиска теперь другое, правила поиска включены сюда) и раздел Каталога в `spec.md` §3.5 в части компоновки.

HTML — **референс дизайна**, не код для переноса. Fidelity — **hi-fi**.

## Каталог

Поля экрана 20 dp, между блоками 22 dp. Порядок сверху вниз:

**1. Шапка** — «Каталог» и кнопка «+» (меню «Своя практика»), без изменений.

**2. Поле поиска**

| Параметр | Значение |
|---|---|
| Высота | **44 dp** |
| Скругление | **22 dp** (полностью круглое) |
| Фон | `card` |
| Отступы | слева 16 dp, справа 8 dp |
| Иконка | Phosphor `magnifying-glass`, `muted` |
| Текст | Nunito Sans 600, 15 sp, `ink`; плейсхолдер **«Поиск»**, `muted` |
| Очистить | при непустом запросе — круг 28 dp, фон `subtle`, «×» `muted` |
| Обводка | 2 dp `accentText` только при непустом запросе; переход 200 мс |

`TextField` без подчёркивания, `singleLine`, `imeAction = Search` (просто скрыть клавиатуру). Поле прокручивается вместе с экраном.

**3. Чипы** — сразу под поиском (расстояние до поля на 10 dp меньше обычного, т. е. 12 dp), горизонтальная прокрутка с выходом за поля, gap 8 dp.
- Порядок: **Все · ♥ · цели** (в порядке `GOALS`). Чисел нет.
- Высота 40 dp, r 20, текст 13 sp 700, отступы 0 / 14 dp. Выбранный — `selBg` / `selFg`, остальные — `card` / `ink`.
- Чип ♥ — круг 40×40, иконка `heart` 18 dp, без текста.
- Выбран всегда ровно один.

**4. Лента «Инструменты и мои практики»** — только при чипе «Все».
- Заголовок: 12 sp 800, капс, трекинг 1, цвет `label`; до ленты 8 dp.
- Горизонтальная лента, gap 8 dp, выходит за поля экрана.
- Карточка: ширина **158 dp**, `card`, r 18, отступы 10 / 12 / 10 / 10 dp, внутри ряд с gap 10 dp: плашка 36 dp (r 12, фон `soft` цели, иконка 20 dp `deep`) и два текста — название 13.5 sp 800, **до 2 строк** с многоточием; подпись 12 sp 700 `muted2`, одна строка.
- Состав и порядок: **Таймер** (подпись — длительность, «10 мин») → **Метроном** («60 уд/мин») → свои практики и ритмы (подпись — длительность или паттерн) → последней **«Своя практика»**: карточка-контур (без заливки, пунктир/обводка, иконка `plus`), открывает то же меню, что «+» в шапке.
- Тап по карточке — как раньше по строке: экран таймера, метронома, плеер своей практики.

**5. Лента «Курсы»** — при «Все» и при чипе цели (курсы этой цели); в режиме ♥ скрыта.
- Заголовок как у ленты выше. Карточка: ширина **236 dp**, `card`, r 22, отступы 14 dp, колонка с gap 10 dp:
  1. плашка 40 dp (r 13, `soft`, иконка `calendar-check` 21 dp `deep`) + название 15 sp 800, до 2 строк;
  2. описание 13 sp `muted`, ровно 2 строки высоты (min 35 dp);
  3. сегменты прогресса: по одному на день, высота 4 dp, r 2, gap 3 dp; пройденные — `deep` цели, остальные — `subtle`;
  4. низ: слева состояние 12 sp 800 `muted2`, справа кнопка-таблетка.
- Состояние и кнопка:

| Курс | Состояние | Кнопка |
|---|---|---|
| не начат | «7 дней» | «Начать» — фон `subtle`, текст `accentText` |
| начат | «День 3 из 7» | «Продолжить» — фон `accent`, текст белый |
| пройден | «Пройден» | «Повторить» — как «Начать» |

- Порядок: начатые → не начатые → пройденные; внутри — как в данных.
- Тап по карточке и по кнопке — экран курса.

**6. Группа «Практики»** — заголовок как у лент, под ним **полный** список, без «Ещё…».
- Сначала простые практики, затем практики из нескольких шагов.
- При чипе цели — только практики этой цели.
- Строка: `card`, r 22, плашка-иконка 48 dp, справа текст:
  - первая строка — название 15 sp 800 (переносится) и **длительность справа в той же строке** («2–10 мин», «3 шага · 13 мин»), 12 sp 800 `muted2`, не переносится;
  - вторая — описание 13 sp `muted`, **до 2 строк**.
  - Замок у платных — как раньше. Стрелки справа нет.

**7. «Скрытое · N»** — ссылка внизу, без изменений.

### Режим ♥

- Ленты «Инструменты и мои практики» и «Курсы» скрыты.
- Одна группа **«Избранное»**: всё, что отмечено сердцем, — инструменты, свои практики, встроенные практики — теми же строками, что в «Практиках».
- Пусто: по центру «В избранном пока пусто» (15 sp 800 `ink`) и «Отметь практику или инструмент сердцем — они появятся здесь» (13 sp `muted`), отступы 32 dp сверху и снизу.

### Чип цели

Ленты «Инструменты и мои практики» нет. Курсы этой цели → практики этой цели. Если пусто: «Здесь пока пусто» / «Выбери «Все» или верни скрытые практики».

## Поиск

Отдельного экрана нет. Пока запрос непустой (после `trim`), **всё под полем скрыто** (чипы, ленты, список, «Скрытое») и показаны результаты. Шапка и нижнее меню остаются.

- Результаты обновляются на каждый ввод, без кнопки и задержки.
- Выбранный чип на поиск не влияет: ищем по всему Каталогу.
- Запрос живёт, пока открыт Каталог; переход в практику и назад его сохраняет. Недавних запросов нет.
- Тап по результату — то же, что тап по этому элементу в Каталоге.

**Как ищем** — только буквальное вхождение подстроки, без морфологии и синонимов.
1. Запрос и текст: нижний регистр, `ё → е`.
2. Запрос делится на слова по пробелам; элемент подходит, если **каждое** слово входит хотя бы в одно поле.
3. Поля:

| Тип | Название | Подзаголовок | Дополнительно |
|---|---|---|---|
| Практика | `title` | строка описания | паттерн / `sub`, направление («Дыхание»…), название цели |
| Практика из шагов | название | цепочка шагов | название цели |
| Курс | название | описание | название цели, «курс» |
| Моя практика / ритм | название | паттерн / цепочка | «своя», «дыхание» |
| Инструмент | «Таймер медитации», «Метроном» | текущие настройки | «инструмент» |

4. Скрытые практики в результаты не попадают.

**Выдача**
- «Найдено: N» — 13 sp, `muted`.
- Группы в порядке **Практики → Курсы → Мои практики → Инструменты**, пустые не показываются. Внутри: совпадение в названии → в подзаголовке → в остальных полях; при равенстве — порядок Каталога.
- Строка — как строка «Практик», подзаголовок в 2 строки. Подсветка всех вхождений в названии и подзаголовке: фон `#E0D7FC` (тёмная тема — `rgba(174,178,242,.28)`), r 4, цвет текста не меняется; соседние куски сливаются.
- Если слово нашлось только в названии цели — подзаголовок «Цель: **Сон** · <обычный подзаголовок>», цель подсвечена.

**Ничего не найдено** — по центру, отступ сверху 36 dp, gap 10 dp:
1. орб 88 dp из двух кругов `own` (α .18 и .35) с иконкой `magnifying-glass` 24 dp;
2. «По «йога» ничего нет» — Nunito 800, 19 sp;
3. «Ищи по названию, цели или направлению: «сон», «дыхание», «метта»» — 14 sp `muted`, max 260 dp;
4. если запрос входит в название скрытой практики — «Есть в Скрытом: <название>» с `eye-slash`, ведёт в «Скрытое»;
5. «Собрать свою практику» — 14 sp 700 `accentText`: очищает поиск и открывает меню «+».

## Сегодня

Верх экрана (приветствие, «Как ты сейчас?», плитки состояний) и блок «На сегодня» — без изменений: до 3 подобранных практик и постоянная строка «Посидеть в тишине · Таймер медитации». Ниже добавляются два блока. Заголовки блоков — Nunito 800, 18 sp; от заголовка до содержимого 10 dp.

**«Продолжить»** — показывается, если есть курс, где пройдено больше 0 и меньше всех дней (берётся первый такой). Иначе блока нет.
- Карточка: `card`, r 20, отступы 12 dp, ряд с gap 14 dp:
  - плашка 48 dp (r 16, `soft` цели, `calendar-check` 24 dp `deep`);
  - колонка (gap 5 dp): название курса 15 sp 800; сегменты прогресса (как в карточке курса); мета 12 sp 800 `muted2`, одна строка с многоточием;
  - кнопка ▶ — круг 44 dp, фон `accent`, иконка fill `play` 18 dp белая.
- Мета: «День N из M · <название дня>»; если следующий день ещё закрыт — «День N из M · откроется завтра».
- Тап по карточке — экран курса.
- Тап по ▶ — **сразу запускает практику дня** с привязкой к курсу (после неё день засчитывается). Если день «откроется завтра» или закрыт подпиской — ▶ открывает экран курса.

**«Избранное»** — показывается, если избранное не пусто.
- Лента тех же карточек 158 dp, что в Каталоге (название до 2 строк — длинные названия не растягивают карточку).
- Состав: всё с сердцем — практики, свои практики, Таймер, Метроном. Подпись: длительность практики («1–10 мин»), у инструмента — текущая настройка.
- Тап — то же, что в Каталоге (карточка практики / экран инструмента / плеер).

Инструментов отдельным блоком на «Сегодня» нет: они живут в Каталоге и попадают сюда через избранное.

## Инструменты в избранном

- На экранах «Таймер медитации» и «Метроном» сердце стоит **в строке заголовка справа** (как у названия в карточке практики), не в шапке: в шапке остаётся только «Назад». Иконка `heart` 24 dp цвета `ink`, **без фона-круга**; в избранном — fill `heart` `#E86A6A`. Зона нажатия 44 dp, правый край иконки — по полю экрана. Заголовок занимает остальную ширину и переносится, не заходя под сердце.
- Идентификаторы в общем списке избранного: **`timer`** и **`metro`** — рядом с id практик.
- Избранный инструмент появляется: в Каталоге в режиме ♥ и на «Сегодня» в ленте «Избранное». В ленте «Инструменты и мои практики» он есть всегда.

## Что удалить

- Ленту «Избранное» и ленту «Недавние» из Каталога.
- Отдельные группы «Мои практики» и «Инструменты» в списке Каталога (кнопка «Настроить» у своих практик в списке тоже уходит — настройка из плеера / карточки).
- Числа в чипах, кнопку «Ещё N…» и сворачивание групп.
- Отдельный экран поиска, если был начат по старому заданию.

## Код

```kotlin
enum class CatalogFilter { ALL, FAVOURITES /* + по одной на цель */ }

sealed interface FavId {                       // общий список избранного
  data class Practice(val id: String) : FavId
  data object Timer : FavId                    // хранится как "timer"
  data object Metronome : FavId                // хранится как "metro"
}

data class StripCardUi(                        // лента 158 dp: Каталог и «Сегодня»
  val title: String, val subtitle: String,
  val icon: CatalogIcon, val goal: Goal,
  val outline: Boolean = false,                // «Своя практика»
  val onOpen: () -> Unit,
)

data class CourseCardUi(
  val id: String, val name: String, val line: String, val goal: Goal,
  val daysDone: Int, val daysTotal: Int,
  val state: String,                           // «7 дней» / «День 3 из 7» / «Пройден»
  val button: CourseButton,                    // START, CONTINUE, REPEAT
)

data class ContinueUi(                         // «Сегодня» → «Продолжить»
  val course: CourseCardUi,
  val meta: String,                            // «День 3 из 7 · Ровный ритм» / «… · откроется завтра»
  val canPlayNow: Boolean,                     // false → ▶ открывает курс
)

data class CatalogUi(
  val query: String, val filter: CatalogFilter,
  val strip: List<StripCardUi>,                // пусто, если filter != ALL
  val courses: List<CourseCardUi>,             // пусто в FAVOURITES
  val groupTitle: String,                      // «Практики» / «Избранное»
  val rows: List<PracticeRowUi>,
  val search: SearchUi?,                       // не null при непустом запросе
)

fun normalize(s: String) = s.lowercase().replace('ё', 'е')
fun search(items: List<CatalogSearchItem>, query: String): List<SearchGroup>
fun highlight(text: String, words: List<String>): AnnotatedString
```

- `CatalogViewModel`: `query`, `filter`, `onQueryChange()`, `clear()`; всё остальное — производные.
- `TodayViewModel`: добавить `continueCourse: ContinueUi?` и `favourites: List<StripCardUi>`.
- Избранное: если сейчас хранится `Set<String>` id практик — оставить и добавить строки `timer` / `metro`; миграция не нужна.
- Карточка ленты — один composable для Каталога и «Сегодня».

## Доступность

- Поле: «Поиск по каталогу»; «×» — «Очистить», зона ≥ 44 dp.
- Чипы: `Role.Tab` / `selected`; у ♥ — `contentDescription` «Избранное».
- «Найдено: N» — `liveRegion = Polite`.
- ▶ в «Продолжить» — «Продолжить курс»; сердце у инструмента — «В избранное: Таймер» / «Убрать из избранного: Таймер» (то же для Метронома).
- Карточка курса: одно действие «Открыть курс»; кнопка внутри не отдельная цель для TalkBack.
- fontScale 2: карточки лент растут по высоте, ширина не меняется; длительность в строке практики переносится под название, если не помещается.
