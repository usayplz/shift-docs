# Задание: одна сущность «практика» вместо «программ»

Источник истины — `prototype/Shift v10 Android.dc.html` и `spec.md` (§3.5–3.9, §4.1, §5.6, §5.8, §5.9, §9).

## Суть
Слова «программа» в интерфейсе больше нет. Всё, что запускается одной сессией, — **практика**:
- простая (одна техника) — как раньше;
- **из нескольких шагов** (бывшая программа) — мета «3 шага · 13 мин», подзаголовок — цепочка шагов;
- **своя**: «Дыхательный ритм» (бывшая своя техника) или «Из нескольких практик» (бывшая своя программа).

Курсы не меняются — это дни, а не одна сессия.

## Модель данных
Не меняется: `Program`, `ProgramStep`, `UserTechnique`, `SessionKind.PROGRAM`, `progId` остаются как внутренние имена. Меняются только тексты и группировка в UI.

## Что поменять
1. **Каталог.** Группы: Инструменты · Мои практики · Курсы · Практики. Встроенные из нескольких шагов — в «Практиках» (с фильтром по цели), свои обоих видов — в «Моих практиках». Иконка строки из шагов — `ph-stack`, ритма — `ph-sparkle`.
2. **Меню «+».** Капс «СВОЯ ПРАКТИКА» (11 sp 800, letter-spacing 1, `label`), под ним «Дыхательный ритм» (`ph-sparkle`) и «Из нескольких практик» (`ph-stack`).
3. **Экран практики из шагов.** Капс «ПРАКТИКА ИЗ НЕСКОЛЬКИХ ШАГОВ» вместо «ПРОГРАММА · ОДНА СЕССИЯ».
4. **Редакторы.** Ритм: заголовок «Новая практика» / «Своя практика», поле «Название практики», ошибка «Дай практике имя». Из шагов: поле «Название практики», кнопка «+ Практика», пусто — «Добавь практику или паузу — они пройдут одной сессией.», под шагом «… · длина практики», удалённый шаг — «Практика удалена», подтверждение удаления — «Используется в практиках: …».
5. **Скрытое.** Один список «Практики», пояснение «Практики, которые ты попросил не предлагать…», пусто — «Все практики снова в подборках».
6. **Лимит без Plus — общий:** 1 своя практика любого вида (`users + uprogs ≥ 1` → paywall с причиной «Бесплатно — одна своя практика. С Plus их может быть сколько угодно.»).
7. **Paywall.** 2 пункта: «Все практики и курсы» — «Под каждую цель и состояние» · «Свои практики без лимита» — «Свой ритм дыхания или несколько практик подряд». Закрытая практика из шагов — ««<название>» — в Shift Plus. Часть практик для каждой цели открыта бесплатно.» Остальные тексты — без «программ» и «техник» (см. spec §9).
8. **Прогресс.** Категория `TimeCat.PROG` — «Из нескольких шагов».
9. **Прочие тексты** (Настройки → Данные, удаление аккаунта и данных, политика, условия, онбординг): «свои техники и программы» → «свои практики»; «практики, программы и курсы» → «практики и курсы».

## Чек-лист
- [ ] Поиск по `strings.xml`: нет «программ» и «техник» (кроме «дыхательных техник» в описании курса).
- [ ] Каталог: нет группы «Программы»; «Перед сном» видна в «Практиках» при фильтре «Сон».
- [ ] Без Plus: после 1 своей практики (любого вида) вторая и «Настроить» готовую из шагов ведут в paywall.
- [ ] Скрытая практика из шагов — в общем списке «Скрытого».
- [ ] Paywall — 2 пункта.
