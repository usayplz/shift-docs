# Плеер: подсказка «Звук выключен»

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`, громкость — через `expect/actual`). Если практика ведётся голосом, а громкость на телефоне на нуле, плеер говорит об этом одной строкой. Практика при этом идёт как обычно.

HTML — **референс дизайна**, не код для переноса. Fidelity — **hi-fi**.

## Источник истины

- `prototype/Shift v10 Android.dc.html` → список экранов → «Плеер — звук выключен». Разметка — блок `volHint` в `data-screen-label="Сессия"`; логика — `volHint`, `volOff` в `renderVals()`, состояние `volZero`. В прототипе громкость не настоящая: нажатие на строку изображает «прибавил звук». **В приложении строка не нажимается.**
- `volume-hint/screens/` — 2× (740×1648, экран 370×824 dp): `01-countdown.png` (отсчёт), `02-breathing.png`, `03-meditation.png` (текстовые шаги), `04-walk.png` (прогулка), `05-dark.png`.
- Если прототип и этот файл расходятся, верен прототип.

## Когда показывать

Строка видна, когда одновременно:
1. открыт плеер практики (включая отсчёт «Приготовься»);
2. практика ведётся голосом: включена кнопка «Голос», либо это «Прогулка пяти чувств» (там голос не отключается);
3. громкость мультимедиа равна нулю.

Строка исчезает сама, как только любое условие перестало выполняться: прибавили громкость, выключили «Голос», вышли из плеера. Появление и исчезновение — fade 200 мс.

Чего **не** делаем:
- не ставим практику на паузу и не показываем окно поверх плеера;
- не меняем громкость за пользователя;
- не показываем строку, если голос выключен кнопкой «Голос»: человек сам так решил;
- не показываем на карточке практики, на «Как теперь?», в Таймере и Метрономе.

## Макет

- Место: по центру, **над полосой прогресса** — низ строки на 202 dp выше низа экрана (над прогрессом остаётся ~22 dp). Вверху экрана не ставить: там «Приготовься» и текст шага.
- Капсула: высота 36 dp, r 18, отступы 12 dp слева и 14 dp справа, фон `glass` плеера (тот же, что у круглых кнопок плеера: белый в светлой теме, тёмный в тёмной).
- Внутри: иконка Phosphor `speaker-slash` 17 dp и текст **«Звук выключен — прибавь громкость»** — 13 sp, 700, в одну строку; цвет `ink` плеера. Gap 8 dp.
- Не нажимается, тени нет.
- Если в этот момент над прогрессом показана строка «Дальше: …» (перед шагом составной практики), подсказка о звуке важнее: «Дальше: …» скрывается, пока она видна.

## Как определять громкость

```kotlin
// commonMain
interface MediaVolume { val isZero: StateFlow<Boolean> }
expect fun rememberMediaVolume(): MediaVolume
```

- **Android:** `AudioManager.getStreamVolume(STREAM_MUSIC) == 0`; обновлять по `ContentObserver` на `Settings.System` или broadcast `android.media.VOLUME_CHANGED_ACTION`. Подписку держать только пока открыт плеер.
- **iOS:** `AVAudioSession.sharedInstance().outputVolume == 0`, наблюдать через KVO. Беззвучный режим (переключатель сбоку) **не считается**: звук практики идёт в категории `.playback` и играет при нём как обычно.
- Наушники, которые подключены, но не надеты, определить нельзя — не пытаемся.
- В `PlayerViewModel`: `volumeHint = isPlayerOpen && voiceGuided && mediaVolume.isZero`.

## Доступность

- При появлении строка объявляется один раз: `liveRegion = Polite`, текст «Звук выключен. Прибавь громкость».
- Иконка декоративная. Контраст текста на `glass` ≥ 4,5:1 в обеих темах.
- fontScale 2: текст переносится на две строки, капсула растёт по высоте и не наезжает на прогресс (растёт вверх).
- Reduce motion: без fade, появляется сразу.

## Проверить

- [ ] Голос включён, громкость 0 — строка есть на отсчёте и во время практики.
- [ ] Прибавили громкость кнопками — строка исчезла, практика не прерывалась.
- [ ] Убавили до нуля во время практики — строка появилась.
- [ ] Голос выключен кнопкой — строки нет при любой громкости.
- [ ] Прогулка: строка показывается при нулевой громкости всегда.
- [ ] iOS: беззвучный режим при ненулевой громкости строку не вызывает, голос слышен.
- [ ] Строка не закрывает прогресс, название фазы и текст шага; с «Дальше: …» не накладывается.
- [ ] Светлая / тёмная тема, 320 dp, fontScale 2, TalkBack / VoiceOver.
