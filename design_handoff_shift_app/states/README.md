# Состояния «Как ты сейчас?» — доработка (вариант 5a)

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`). Меняются названия и описания 4 состояний и вид карточки на «Сегодня». Логика подбора, цвета и внутренние оси `e`/`t` не меняются.

## Источник истины

- `prototype/Состояния - варианты.dc.html` → #5a рядом с отклонёнными вариантами.

## Тексты

| Ключ | Было | Стало | Описание (было → стало) |
|---|---|---|---|
| `CALM_ENERGY` | Собран | **В порядке** | Ясно и спокойно — лучшее состояние → **Силы есть, внутри спокойно** |
| `TENSE_ENERGY` | На взводе | На взводе | Энергия есть, но всё сжато → **Силы есть, внутри всё сжато** |
| `CALM_TIRED` | Вяло | **В тумане** | Мало сил, но спокойно → **Сил мало, внутри спокойно** |
| `TENSE_TIRED` | Выжат | **На пределе** | Сил нет, а нервы натянуты → **Сил мало, а нервы натянуты** |

Почему меняем:
- **Без рода.** «Собран» и «Выжат» написаны в мужском роде, новые названия — без рода и одной грамматической формы.
- **Без оценки.** Убрали «лучшее состояние»: остальные карточки рядом с ним звучали как «у тебя хуже».
- **Одна схема описаний** «сколько сил + что внутри»: состояния быстрее сравнивать.

Названия поменять **везде**, где показывается состояние: история сессий, «Было: …» на «Как теперь?», «Что помогает» на «Прогрессе», шторки редактирования сессии, строки ресурсов, тексты бесплатного набора. Готовая карта названий — `QUAD_NAME` в `progress/ProgressLogic.kt`. Enum и сохранённые данные не трогать — меняются только подписи.

## Карточка на «Сегодня»

Сетка 2×2, gap 8 dp (как было).

- Плитка: фон `q1…q4` (светлая) / тёмный аналог, текст `q1i…q4i`, r 22 dp, padding **20 dp сверху, 16 dp по бокам, 14 dp снизу**. Минимальной высоты нет (было `min-height 104`). Контент прижат к началу, без растяжки `space-between`.
- **Орб 22 dp** вместо точки 14 dp: внешний круг — цвет состояния с прозрачностью 35 % (`dot` + альфа `0x59`), внутри круг 12 dp цвета `dot`.
- Отступ орб → название **12 dp**, название → описание 2 dp.
- Название: Nunito Sans 800, 16 sp. Описание: 13 sp / 1.3, opacity 0.85.
- Нажатие: scale 0.97, как раньше. Тап сразу открывает подбор (как было).

```kotlin
@Composable fun StateCard(q: Quad, onClick: () -> Unit, modifier: Modifier = Modifier)
@Composable fun StateOrb(dot: Color, size: Dp = 22.dp)   // halo = dot.copy(alpha = .35f), inner = size * 12 / 22
```
