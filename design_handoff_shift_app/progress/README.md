`LazyColumn`, фон `bg`, отступы: сверху status bar inset + 18 dp, по бокам 20 dp, снизу 140 dp (под плавающую навигацию). Между блоками 22 dp.

3. **Календарь** — карточка `card`, r 22, padding 16, gap 12.
   - Шапка: ‹ 36 dp круг `subtle` · по центру месяц (Nunito 800 18; год добавляется, если не текущий) и подпись 13 sp `muted` · › (неактивна на текущем месяце, alpha .35).
   - Подпись: «14 дней · легче в 12 из 15» / «нет практик».
   - Сетка 7 колонок, gap 4, ячейка квадратная. Шапка дней: пн…вс, 11 sp 800 `muted`. Неделя с понедельника.
   - Ячейка: есть оценённые сессии → лицо лучшей оценки дня (86 % ячейки); есть сессии без оценки → число + точка 5 dp `accent`; нет → число 13 sp `muted`. Сегодня — число `accentText` 800, если пусто — inset-обводка 2 dp `subtle`. Будущие дни — `dot`, не нажимаются.

4. **«Что помогает, когда ты…»** — Nunito 800 18.

5. **Карточка «Время практик»** (стоит перед «Сессиями») — `card` r 22 padding 16, вся карточка кликабельна → шторка «Время практик».

## Шторки (M3 `ModalBottomSheet`)

Общее: фон `bg`, скругление 28 dp сверху, padding 14/20/34, ручка 40×5 `dash`, заголовок Nunito 800 22 + кнопка ✕ 44 dp круг `card`. Максимум 88 % высоты, содержимое прокручивается. Подписи секций — капс 12 sp 800 `label`, «· необязательно» — 12 sp 700 `muted` без капса.

**Шторка дня** (`05`): заголовок «Сегодня» / «Вчера» / «7 октября», под ним «2 сессии». Список `SessionRow` с иконкой карандаша справа. Внизу пунктирная кнопка 50 dp, r 20, обводка 2 dp `dash`: «+ Добавить сессию в этот день».

**Время практик** (`03`, `04`):
- Сегменты 2 колонки (дорожка `subtle` r 14 pad 3; кнопка 38 dp r 12; выбранная `card` + `ink`, остальные `muted`; 14 sp 800): «<месяц календаря>» / «Всё время». Месяц меняется стрелками календаря.
- Чипы-фильтр (горизонтальный скролл, выходит за padding): «Все» + только типы, у которых есть сессии за период, в порядке: Дыхание · Медитация · Таймер · Тело · Психотехника · Транс · Программы. Чип 36 dp r 18, 13 sp 700; выбранный `selBg`/`selFg`, остальные `card`/`ink`.
- Карточка `card` r 22 padding 16 gap 16: сумма Nunito 800 30 tabular («2 ч 21 мин», пусто — «0 мин»); «18 сессий · 14 дней» 13 sp `muted`.
- Строки практик по убыванию времени: точка 10 dp цвета цели · название 14 sp 800 (ellipsis) · «3 раза» 12 sp `muted` · время 14 sp 800 tabular, мин. ширина 70 dp, справа. Под строкой полоса 6 dp r 3: дорожка `subtle`, заливка цветом цели, ширина = время / время лидера (минимум 3 %).
- Первые 5, затем «Показать все · 11» / «Свернуть». Пусто: «В этом месяце практик пока не было» / «Практик пока не было».
- При смене периода или фильтра список сворачивается обратно до 5.

**Редактировать сессию** (`06`): заголовок — название практики, под ним время.
1. «Как было до» — сетка 2×2 кнопок 44 dp r 16 (точка 12 + название 13 sp 700). Выбранная: фон `subtle` + inset 2 dp `accentText`; остальные: inset 1.5 dp `line`, текст `muted`. Повторный тап снимает выбор.
2. «Как стало» — 4 лица 44 dp в колонках, подписи Хуже / Так же / Лучше / Отлично 12 sp. Выбранное: фон `subtle` + inset 2 dp `accentText`, 800; невыбранные alpha .55, если что-то выбрано.
3. «Длительность» — степпер 56 dp r 18 `card`: − (44 dp круг `subtle`, alpha .4 при 0) · значение Nunito 800 18 tabular · +. Шаг 1 мин. При дробной длительности «−» сначала округляет вниз до целой минуты. 0 → «Не указано». Максимум 600 мин.
4. «Заметка» — поле r 16 `card`, 3 строки, до 280 символов, плейсхолдер «Что заметил? Мысли, ощущения…».
5. «Сохранить» 56 dp pill `accent`; «Удалить сессию» 40 dp текст `danger`. Удаление в два тапа: после первого — «Точно удалить? Нажми ещё раз».

**Новая сессия** (`07`): «Практика» (чипы 40 dp в горизонтальном скролле: «✎ Своя» + все практики; «Своя» показывает поле «Например: прогулка, растяжка», до 60 символов) · «Когда» (чипы Сегодня / Вчера / Позавчера, плюс выбранный день, если он раньше; колёса ч : мин, высота 132, строка 44) · «Длительность» (по умолчанию рек. длительность выбранной практики, иначе 5 мин) · «Как было до» · «Как стало» · «Заметка» · «Добавить сессию». Всё кроме времени необязательно.

**Все сессии** (полноэкранный, назад ←): заголовок 26 sp, поиск — pill 48 dp `card` с лупой, «Поиск по заметкам и практикам», ✕ очищает. Подпись «20 сессий за всё время» / «Найдено: N». Список `SessionRow`. Пусто: «Ничего не нашлось».

## Данные

```kotlin
enum class SessionKind { PRACTICE, PROGRAM, TIMER }

@Entity data class SessionEntity(
  @PrimaryKey val id: String,
  val pid: String?,            // встроенная практика или id своей техники
  val progId: String?,
  val title: String?,          // своё название / программа / «Таймер медитации»
  val kind: SessionKind,
  val beforeQuad: Quad?,       // «Как было до» (в UI — одна из 4 карточек)
  val rating: Int?,            // 0 Хуже · 1 Так же · 2 Лучше · 3 Отлично
  val note: String?,
  val at: Instant,
  val durationSec: Int,        // фактическое время, 0 = не указано
)
```

DAO: `observeAll(): Flow<List<SessionEntity>>` (сортировка по `at` desc), `upsert`, `delete`. Вся агрегация — в памяти через `ProgressLogic.kt` (сессий мало, Room-агрегаты не нужны).

**Как записывается `durationSec`** (§5.9):
- практика или программа — проиграно без отсчёта «Приготовься» и пауз; при раннем выходе — до момента выхода;
- таймер — `elapsed − warmSec`;
- пробный запуск из редактора не пишется;
- метроном пока не пишется.

`ProgressViewModel` → `StateFlow<ProgressUi>`. Отдельное UI-состояние: `monthOffset`, `helpQuad`, `timePeriod`, `timeCat`, `timeExpanded`, открытая шторка (`Day(date)`, `Time`, `Edit(id)`, `Add(date)`).

## Проверить

- [ ] Сводка в шапке считает время по всем сессиям.
- [ ] Стрелки календаря меняют и месяц на карточке «Время практик», и период «месяц» в шторке.
- [ ] В шторке видны только типы с сессиями за выбранный период; при смене периода выбранный тип сбрасывается на «Все», если его нет.
- [ ] Таймер попадает в тип «Таймер», своя техника — в «Дыхание», программа без практики — в «Программы».
- [ ] Строка сессии — три строки: время и длительность / до → после / заметка.
- [ ] Длительность редактируется и в «Новой сессии», и при редактировании; 0 → «Не указано», строка без «· N мин».
- [ ] Пустое состояние: календарь виден, остальные блоки скрыты.
- [ ] Тёмная тема: всё берёт цвета из `DarkShift`, лица и точки без изменений.
- [ ] TalkBack/VoiceOver: у ячеек календаря `contentDescription` «7 октября, 2 сессии, лучше»; у ✕ — «Закрыть».
