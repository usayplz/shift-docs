# Плеер практики: нижняя панель (вариант 2a, «Симметрия за счёт „Заново“»)

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`). Меняется только нижняя панель плеера. Звук дыхания убираем из приложения. Шапка, орб, фон, «Приготовься» и экран «Как теперь?» остаются прежними.

HTML-файлы — **референс дизайна**, а не код для переноса. Экран нужно воссоздать в текущем Compose-проекте, используя его паттерны и токены. Fidelity — **hi-fi**: цвета, размеры и шрифты финальные.

- `prototype/Плеер - варианты.dc.html` → секция «Плеер без „Дыхания“», макет **#2a**. Варианты 2b, 2c, 3a и 3b отклонены (3a/3b — 2a с подписями; подписи не берём).

## Макет нижней панели (сверху вниз)

`Column`, по центру, gap 12 dp, по бокам 20 dp, снизу nav bar inset + 30 dp.

1. **Следующая фаза**: 14 sp, weight 800, цвет `deep` цели, высота 20 dp, по центру («Дальше: задержка»).
2. **Прогресс**: сегменты высотой 4 dp, r 2 dp, gap 4 dp, вес сегмента = его длительность. Трек `track`, заливка `deep`, ширина заливки анимируется линейно 150 мс. Под полосой через 8 dp — строка высотой 18 dp: слева прошедшее время «0:42», справа оставшееся «−2:18». Шрифт 13 sp, weight 700, цвет `body2`, tabular figures.
3. **Ряд управления**: 3 колонки `1fr · auto · 1fr`, по вертикали по центру.
   - Слева: **Голос**, **Тон**. Справа: **Вибро**, **Заново**. В каждой половине кнопки распределены через `SpaceAround`.
   - **Переключатель** (Голос, Тон, Вибро): круг 44 dp, иконка 20 dp (Phosphor regular: `microphone`, `bell`, `vibrate`).
     - вкл.: фон `pill`, иконка `ink`;
     - выкл.: прозрачный фон, обводка 1.5 dp `dash` (inset), иконка `muted`;
     - фон и обводка меняются с анимацией 200 мс.
   - **Заново**: тот же круг 44 dp, всегда в стиле «вкл.» (фон `pill`, иконка `ink`). Иконка Phosphor regular `arrow-counter-clockwise`, 20 dp. Состояния вкл./выкл. у неё нет.
   - **Пауза / Продолжить**: круг 68 dp, фон `#FFFFFF`, тень `0 14 30 −10 rgba(40,45,90,.35)`. Иконка Phosphor fill `pause` / `play`, 28 dp, цвет `deep` цели. В тёмной теме кнопка тоже белая.
4. **Ссылка**: `Row` высотой 28 dp, по центру. Текстовая кнопка «Закончить и оценить» (в пробном запуске из редактора — «Вернуться в редактор»), 14 sp, weight 700, цвет `deep`, padding 4 dp.

**Орб**: кнопки поверх него нет. На паузе в центре слово «Пауза» (Nunito 800, 26 sp), в остальное время — счёт или фаза.

**Тёмная тема** использует те же токены (`pill`, `dash`, `muted`, `ink`, `track`, `body2`, `deep`) из `DarkShift` и тёмной палитры целей.

## Поведение

- Тап по кнопке паузы или по пустому месту экрана переключает «пауза ↔ идёт». Тапы по переключателям, «Заново» и ссылке паузу не трогают: событие поглощается.
- Пауза останавливает таймер фаз, голос, тон и вибрацию. «Продолжить» возобновляет с того же места.
- Переключатели срабатывают сразу, без паузы. Состояние хранится в настройках под теми же ключами, что в «Настройки → Плеер». При выключении «Голоса» текущая фраза обрывается (`speechSynthesis.cancel` / `TextToSpeech.stop`).
- **Заново** (доступно в любой момент: идёт, пауза, «Приготовься»):
  1. оборвать текущую фразу голоса;
  2. сбросить прогресс на «Приготовься» (`elapsed = −3`);
  3. сразу запустить (`running = true`), даже если до этого была пауза.

  План, длительность и настройки звука сохраняются. Сессия в историю не записывается.
- «Закончить и оценить» и ✕ работают как раньше.
- Если включён «Не гасить экран» — как раньше.

## Удаление «Звука дыхания»

- Плеер: переключателя нет (ряд выше).
- Настройки → Плеер: остаются «Голосовое ведение», «Звук тона», «Вибрация», «Не гасить экран».
- Онбординг (шаг со звуком): остаются Голос, Тон, Вибро.
- Код: удалить ключ настройки `breath`, `playBreath` / `stopBreath` / `loadBreath` и ассет `sounds/breath-615047.mp3` (и его строку в `sounds/CREDITS.md`). Миграция: сохранённое значение `breath` игнорировать.

## Доступность

- Переключатель: `Role.Switch`, `stateDescription` «вкл.» / «выкл.». contentDescription: «Ведение голосом», «Звук смены фазы», «Отклик на вдохе и выдохе».
- Заново: `Role.Button`, contentDescription «Начать заново».
- Пауза: `Role.Button`, contentDescription «Пауза» / «Продолжить».
- Зона нажатия не меньше 44 dp у всех кнопок. На экране шириной 320 dp промежуток между кнопками не меньше 8 dp.
- При fontScale 2 ряд не меняется (текста в нём нет), ссылка может переноситься.

## Код

```kotlin
data class PlayerControlsUi(
  val nextLabel: String,            // «Дальше: задержка» или ""
  val segments: List<Segment>,      // weight, fill 0..1
  val elapsed: String, val left: String,
  val running: Boolean,
  val finishLabel: String,          // «Закончить и оценить» / «Вернуться в редактор»
  val toggles: List<ToggleUi>,      // ровно 3, порядок: voice, sound, vib
)
data class ToggleUi(val key: SoundKey, val icon: ImageVector, val description: String, val on: Boolean)
enum class SoundKey { Voice, Sound, Vib }   // Breath удалён

@Composable fun PlayerControls(ui: PlayerControlsUi, onTogglePause: () -> Unit, onToggle: (SoundKey) -> Unit, onRestart: () -> Unit, onFinish: () -> Unit)
// ряд: [toggles[0], toggles[1]] | PauseButton | [toggles[2], RestartButton]
@Composable fun SoundToggle(t: ToggleUi, onClick: () -> Unit)          // 44 dp
@Composable fun RestartButton(onClick: () -> Unit)                     // 44 dp, стиль «вкл.»
@Composable fun PauseButton(running: Boolean, tint: Color, onClick: () -> Unit)   // 68 dp
```

`PlayerViewModel.restart()`: остановить TTS → `elapsed = -3` → `running = true`. Флаг `canRestart` больше не нужен.
