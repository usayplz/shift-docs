# Онбординг: доработка

Задание для Claude Code (Compose Multiplatform, UI в `commonMain`). Меняются три блока экрана онбординга. Орб, приветствие, дисклеймер, кнопки «Пропустить» / «Начать», автопрокрутка и смена цвета под цель остаются прежними.

HTML-файлы — **референс дизайна**, а не код для переноса. Экран нужно воссоздать в текущем Compose-проекте, используя его паттерны и токены. Fidelity — **hi-fi**.

## Источник истины

- `prototype/Shift v10 Android.dc.html` → экран `data-screen-label="Онбординг"` (в прототипе: список экранов → «Запуск — первый раз» или Настройки → «Показать онбординг снова»). Логика — `ob.goals`, `ob.tiles`, `defs`, `demo`.
- Карточки состояний на «Сегодня» (`homeQuads`, разметка под «Как ты сейчас?») — образец для карточек целей.
- Если прототип и этот файл расходятся, верен прототип.

## 1. «Что тебе сейчас важнее?»

Заголовок без изменений: Nunito 800, 20 sp / 1.2, `ink`. Под ним через 12 dp:

- `LazyVerticalGrid` не нужен, хватит 2 `Row` × 2 карточки: колонки `1fr 1fr`, gap 8 dp. Порядок: Фокус, Сон / Спокойствие, Энергия.
- **Карточка** (как карточка состояния на «Сегодня»):
  - форма r 22 dp, padding 20 / 16 / 14 / 16 dp (верх / бока / низ), `Column`, выравнивание по левому краю, gap 12 dp;
  - фон — `soft` цели, **у всех карточек всегда** (не только у выбранной);
  - сверху **точка**: круг 22 dp цвета цели с альфой 0x59 (≈35 %), в центре круг 12 dp цвета цели (`color`);
  - **название**: Nunito Sans 800, 16 sp, `ink`;
  - **подпись**: Nunito Sans, 13 sp / 1.3, `ink` с альфой 0.85, перенос по словам;
  - **выбрана**: обводка внутрь 2.5 dp цвета `deep` цели, в правом верхнем углу (top 14, right 14 dp) иконка Phosphor fill `check-circle` 22 dp цвета `deep`. Появление галочки — opacity 200 мс, обводки — 150 мс;
  - нажатие: scale 0.97.

Подписи:
- Фокус — Собраться и удержать внимание
- Сон — Замедлиться и легче заснуть
- Спокойствие — Снять напряжение и тревогу
- Энергия — Взбодриться без кофе

Поведение без изменений: тап выбирает цель (`prefGoal`), орб и свечение перекрашиваются, после первого выбора экран плавно прокручивается вниз и появляются блоки 2 и 3.

## 2. «Как вести практику?»

Заголовок и подзаголовок без изменений. Под ними:

- Сетка из **3 колонок** `1fr 1fr 1fr`, gap 8 dp. Плитки занимают всю ширину, ряд симметричен.
- **Плитка**: r 20 dp, padding 14 / 6 / 12 dp, `Column` по центру, gap 8 dp.
  - иконка Phosphor regular 26 dp: Голос — `microphone`, Тон — `bell`, Вибро — `vibrate` (те же, что в плеере);
  - короткое название 14 sp 800 и под ним состояние «вкл» / «выкл» 12 sp `muted`;
  - вкл.: фон `card`, тень `0 8 18 −12 shadow`, иконка и название `ink`;
  - выкл.: прозрачный фон, обводка внутрь 1.5 dp `line`, иконка и название `muted`;
  - смена — фон и обводка 200 мс.
- По умолчанию включены Голос и Вибро. При включении — короткое демо (голос «Вдох… и выдох», два тона, паттерн вибрации), как раньше.
- Плитки «Дыхание» больше нет: звук дыхания удалён из приложения (см. `player/README.md`).

## 3. Что есть в Shift

Вместо подписи и двух карточек — одна строка, сразу над дисклеймером (gap 8 dp, у дисклеймера свой верхний отступ 10 dp):

> Собраться, успокоиться, заснуть, взбодриться — для каждой цели есть практики, программы и курсы. Таймер и метроном — для своей практики.

Nunito Sans 14 sp / 1.5, цвет `body`, перенос по словам (`LineBreak.Paragraph`). Не нажимается.

## Доступность

- Карточка цели: `Role.RadioButton`, `selected` = выбрана, contentDescription «Фокус. Собраться и удержать внимание». Группа — `selectableGroup()`.
- Плитка звука: `Role.Switch`, `stateDescription` «вкл.» / «выкл.», contentDescription «Ведение голосом» / «Звук смены фазы» / «Отклик на вдохе и выдохе».
- При fontScale 2 карточки целей растут по высоте (в ряду — по самой высокой), текст не обрезается. Плитки допускают перенос подписи.
- Ширина 320 dp: карточки целей ≥ 136 dp, плитки ≥ 88 dp.

## Код

```kotlin
data class GoalCardUi(val goal: Goal, val name: String, val line: String, val color: Color, val soft: Color, val deep: Color, val selected: Boolean)
data class SoundTileUi(val key: SoundKey, val icon: ImageVector, val short: String, val description: String, val on: Boolean)

@Composable fun GoalGrid(items: List<GoalCardUi>, onPick: (Goal) -> Unit)        // 2×2
@Composable fun GoalCard(ui: GoalCardUi, onClick: () -> Unit)
@Composable fun SoundTiles(items: List<SoundTileUi>, onToggle: (SoundKey) -> Unit) // 3 колонки
```

`GoalCard` и `StateCard` с «Сегодня» стоит собрать на одном базовом компоненте (`ChoiceCard`: фон, точка, название, подпись, выбранность). `SoundKey.Breath` удалить. Карточки «Таймер» / «Метроном» из онбординга удалить. Строки — в `strings`.
