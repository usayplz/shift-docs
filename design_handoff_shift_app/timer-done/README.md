# Итог таймера медитации — задание для Claude Code (Compose Multiplatform)

Экран после окончания или остановки таймера медитации. UI в `commonMain`, логика — чистый Kotlin.

## Файлы в этой папке

| Файл | Куда | Что |
|---|---|---|
| `TimerDoneLogic.kt` | `shared/domain/timer/` | `timerDoneUi()` — заголовок, мета, карточки. Без Compose |
| `TimerDoneLogicTest.kt` | `shared/commonTest/.../timer/` | Тесты логики |
| `TimerDoneScreen.kt` | `shared/ui/timer/` | `TimerDoneScreen`, `StatCard`, `MeditationBadge` + `@Preview` |

Зависимости: `compose/ShiftColors.kt` (`Shift.colors`), `compose/ShiftIcons.kt` (`ShiftIcons.Meditation`), `progress/ProgressLogic.kt` (`Session`, `SessionKind`, `formatDuration`, `plural`).
Источник истины — `prototype/Shift v10 Android.dc.html`: Каталог → Посидеть в тишине → Старт → Завершить (через 30+ с). Разметка — блок `<!-- TIMER DONE -->`, логика — `stopTimer`, `tdTitle`, `tdMeta`, `tdStats`, `timerFinish`, `timerHowNow`. Если расходится с этим файлом — прав прототип.

## Когда показывается

- «Завершить» и `elapsed − warmSec > 30 с` → итог.
- «Завершить» и ≤ 30 с → назад на настройку таймера, сессия **не** пишется.
- Таймер с длительностью дошёл до конца (`elapsed ≥ warm + dur`) → итог автоматически.
- Бесконечный таймер — тот же экран.
- При входе играет звук «Конца» (`cfg.end`, если не «Нет»), 1,6 с.

## Макет (сверху вниз)

`Column`, фон `bg`, отступы: сверху systemBars + 22 dp, по бокам 20 dp, снизу systemBars + 30 dp, gap 22 dp. Без верхней панели и ✕.

1. **Центр** — `weight(1f)`, по центру, gap 14 dp.
   - Круг 128 dp, `subtle`; `ShiftIcons.Meditation` 66 dp, tint `accentText`.
   - Заголовок — Nunito 800, 28 sp / 1.2, `ink`, по центру.
     `n = round(played / 60)`: `n > 0` → «%d минута / минуты / минут тишины», `n = 0` → «Меньше минуты тишины». `played = elapsed − warmSec`.
   - Мета — 13 sp `muted`, через « · »: звук начала («Чаша», «Гонг»…; нет при «Нет») · «N интервалов» (нет при 0) · «ЧЧ:ММ–ЧЧ:ММ» (конец − played … конец).
2. **Карточки** — `Row`, gap 8 dp, обе `weight(1f)`, одной высоты. `card`, r 20 dp, padding 14/16 dp, gap 2 dp.
   - Подпись — 12 sp 800, капс, letterSpacing 1 sp, `label`.
   - Значение — Nunito 800, 22 sp, tabular, `ink`.
   - Снизу — 12 sp `muted`.

   | Карточка | Значение | Снизу |
   |---|---|---|
   | СЕГОДНЯ | сумма `durationSec` за сегодня | «N сессий» |
   | ЗА НЕДЕЛЮ | сумма за сегодня + 6 дней до | «M дней из 7» |

   Обе включают текущую сессию. Считаются **все** сессии (практики, в т.ч. из нескольких шагов, и таймер). `formatDuration`: «45 с», «35 мин», «1 ч 50 мин»; 0 → «0 мин». M — дни с ≥ 1 сессией, минимум 1.
3. **Текст** — 13 sp / 1.5 `muted`, по центру: «Сессия сохранена. Отметь, как ты сейчас, — увидишь сдвиг.»
4. **Кнопки** — `Row`, gap 10 dp, высота 56 dp, pill.
   - «Готово» — `weight(1f)`, фон `second`, `ink` 15 sp 700, одной строкой.
   - «Как теперь?» — `weight(2f)`, фон `Shift.colors.accent` (Brush), белый 16 sp 700.

Тёмная тема — те же токены (`DarkShift`), отдельной вёрстки нет.

## Поведение

- **Сессия пишется при входе на экран**: `kind = TIMER`, `title = "Таймер медитации"`, `pid = null`, `before = null`, `rating = null`, `durationSec = played`, дата/время = момент остановки. (В прототипе запись происходит при выходе — в приложении пишем сразу, чтобы «Сессия сохранена» было правдой и запись не терялась при убийстве процесса. Результат для пользователя тот же.)
- Карточки считаются из `SessionRepository.observeAll()` уже **после** записи — текущая сессия попадает в суммы сама, отдельно не прибавлять.
- «Готово» и системный «назад» → вкладка «Сегодня».
- «Как теперь?» → экран «Как теперь?» (`AfterScreen`) с `editSessionId = id`: только заголовок «Как теперь?», без строки «Было:» (у таймера нет «до»), 4 карточки состояний (Собран / На взводе / Вяло / Выжат). «Готово» → `update(id, rating, note)`, «Пропустить» → ничего не меняет. Дубль не создаётся. Дальше → «Сегодня».
- Переход с сессии таймера — «bloom»: старый экран fade-out 200 мс; новый — fade-in + scale 0.92 → 1, 620 мс, пружина `cubic-bezier(.34,1.3,.5,1)` (в Compose: `spring(dampingRatio = 0.7f, stiffness = Spring.StiffnessMediumLow)`), задержка 90 мс. Экран целиком, без поэлементного каскада. «Уменьшить движение» → без анимации.

## Доступность

- Карточка — одна фраза: `Modifier.semantics(mergeDescendants = true)`, contentDescription «Сегодня, 35 мин, 2 сессии».
- Заголовок — `heading()`. Иконка — декоративная (`contentDescription = null`).
- fontScale 2: карточки растут по высоте, «Готово» не переносится.

## Проверить

- [ ] Завершить через ≤ 30 с → настройка таймера, в истории пусто.
- [ ] Завершить через 20 мин → «20 минут тишины», в истории одна запись «Таймер медитации · 20 мин».
- [ ] «Как теперь?» → выбрать состояние → «Готово»: та же запись получила оценку, новой нет.
- [ ] «Как теперь?» → «Пропустить»: запись без оценки, одна.
- [ ] Карточки включают текущую сессию; «M дней из 7» ≥ 1.
- [ ] Без звука начала и интервалов мета = «07:15–07:35».
- [ ] Таймер с длительностью сам открывает итог и играет звук конца.
- [ ] Светлая / тёмная тема, fontScale 2, TalkBack / VoiceOver.

## Что изменилось относительно прошлой версии задания

- Анимация входа — «bloom» экраном целиком, как в прототипе (было: каскад центр / карточки / кнопки).
- На экране «Как теперь?» для таймера **нет** подзаголовка «20 минут тишины» — только «Как теперь?» (как в прототипе).
- Добавлены: звук конца при входе, автопереход по окончании длительности, «Пропустить» на оценке.
- Готовый код: `TimerDoneLogic.kt`, тесты, `TimerDoneScreen.kt`.
