# Shift — дизайн и логика приложения

Источник истины — прототип `Shift v10 Android.dc.html` (переключатель iOS / Android). Если документ и прототип расходятся, верен прототип.
Целевой стек: **Compose Multiplatform** (Android + iOS), **Material 3** с собственной темой.

---

## 1. Суть продукта

Ядро — короткий цикл:

**Отметил состояние → короткая практика → «Как теперь?» → видишь сдвиг.**

- Состояние — одна из 4 карточек: В порядке / На взводе / В тумане / На пределе. Карты состояний в интерфейсе нет; внутри каждое состояние хранится как пара `e` (энергия) и `t` (напряжение) в диапазоне −1..1 — только для расчёта сдвига (§5.5).
- Практика подбирается под состояние, цель и время суток.
- История сессий показывает, что именно помогает пользователю.
- Отдельно есть инструменты: **Таймер медитации** и **Метроном**.

Тон текстов: на «ты», коротко, без давления и медицинских обещаний.

### 2.6 Движение

- Переход внутри сессии (карточка → плеер → «Как теперь?»): opacity 450 мс, сдвиг Y 10–14 dp за 600 мс, easing `cubic-bezier(.2,.8,.2,1)` → `CubicBezierEasing(0.2f, 0.8f, 0.2f, 1f)`.
- Орб плеера масштабируется по фазе дыхания (вдох — рост, выдох — сжатие), каждые 150 мс линейно.
- Появление блоков онбординга: fade + slide 14 dp, 500 мс.
- Нажатие кнопки: scale 0.96.
- Уровень анимации (полная / сдержанная / без анимации) — переключатель прототипа для проверки, не пункт настроек. В приложении — полная анимация; при системном «уменьшить движение» — без анимации.

## 3. Навигация и экраны

```
Splash ─┬─▶ Онбординг (только первый запуск) ─▶ Сегодня
        └─▶ Сегодня (все следующие)

Онбординг ─▶ Сегодня ◀─────────────┐
               │                    │
   ┌───────────┼──────────┬─────────┴──┐
 Сегодня    Каталог    Прогресс    Настройки        ← нижняя навигация
   │           │          │
   ▼           ▼          ▼
 Подбор     Карточка   Все сессии
   │        практики       │
   ▼           │       Добавить сессию
 Сессия ◀──────┘
 (карточка → плеер → «Как теперь?»)

 Каталог ─▶ Программа ─▶ Редактор программы
         ─▶ Курс
         ─▶ Своя техника (редактор)
         ─▶ Таймер ─▶ Сессия таймера ─▶ Готово
         ─▶ Метроном ─▶ Сессия метронома
         ─▶ Скрытое
```

Вкладки нижней навигации видны только на корневых экранах: Сегодня, Каталог, Прогресс, Настройки.

### 3.0 Запуск (splash)

- Знак, цвета и файлы — §2.8.
- Системный splash (Android 12+ SplashScreen API, iOS Launch Screen): знак по центру, фон `#F5F4FE` / тёмная `#141416`, внешнее кольцо Ø 140 dp.
- Затем своя анимация `ShiftSplashOverlay` (~1,6 с): кольца выравниваются в орб (900 мс), орб растворяется с ростом ×1,6 (700 мс); экран под ним появляется каскадом (fade + сдвиг 12 dp, задержки 150 / 230 / 310 / 390 мс).
- Ресурсы: `compose/android/res/` (adaptive + monochrome иконка, splash_icon, тема `Theme.Shift.Starting`), `compose/ShiftSplash.kt`, `compose/icon-png/` (iOS 1024 светлая / тёмная / tinted, Play 512, глиф Launch Screen @3x).
- **Первый запуск** → Онбординг. **Дальше всегда** → Сегодня.
- При «уменьшить движение» — без анимации, мгновенный переход.

### 3.1 Онбординг (один прокручиваемый экран)

1. Анимированный орб (концентрические круги, «дышит» 4 с), заголовок «Привет! Это Shift» и подзаголовок.
2. **«Что тебе сейчас важнее?»** — сетка 2×2 карточек целей в стиле карточек состояний на «Сегодня» (фон `soft` цели, точка с ореолом, название, строка; выбранная — обводка 2,5 dp `deep` и галочка). Фокус / Сон / Спокойствие / Энергия, с подписями (подробно — `onboarding/README.md`):
   - Фокус — Собраться и удержать внимание
   - Сон — Замедлиться и легче заснуть
   - Спокойствие — Снять напряжение и тревогу
   - Энергия — Взбодриться без кофе
3. После выбора цели (экран плавно прокручивается вниз) появляются:
   - **«Как вести практику?»** — 3 плитки-переключателя во всю ширину: Голос / Тон / Вибро, иконки как в плеере (`microphone`, `bell`, `vibrate`). По умолчанию включены **Голос и Вибро**. При включении проигрывается короткое демо.
   - **Что есть в Shift** — одна строка без карточек: «Собраться, успокоиться, заснуть, взбодриться — для каждой цели есть практики, программы и курсы. Таймер и метроном — для своей практики.»
   - **Дисклеймер** с иконкой аптечки: Shift — не медицинская помощь; противопоказания указаны в карточке; закружилась голова — остановись.
4. Кнопка внизу: до выбора — «Пропустить» (вторичная), после — «Начать» (главная).

Цвет орба и фонового свечения меняется под выбранную цель.
Выбранная цель сохраняется как `prefGoal`. Онбординг можно открыть снова: Настройки → «Показать онбординг снова».

### 3.2 Сегодня

- Приветствие по времени суток.
- **«Как ты сейчас?»** + «Отметь — подберём практику под состояние» — сетка 2×2 из состояний (название и ощущение). Тап сразу открывает Подбор.
- **«На сегодня»** — 3 практики под время суток (см. §5.3); если задана `prefGoal` — рядом чип цели. Вечером первой идёт карточка «Перед сном» («Удлинённый выдох · 3 мин, затем тишина»).
- **«Посидеть в тишине»** — «Таймер медитации · <длительность · N интервалов>», вход в Таймер.

### 3.3 Подбор практики

- Сверху — выбранное состояние. Чипы «Куда сдвинуться?» в один ряд: 4 цели, по умолчанию выбрана цель из §5.2.
- Hero-карточка: маршрут (капс, например «СНИЗИМ НАПРЯЖЕНИЕ»), название, мета, объяснение, кнопка «Начать · N мин». Декоративные мягкие формы в правом верхнем углу не перекрывают текст.
- «Или» — 2 альтернативы списком.

### 3.4 Сессия (один экран, три состояния)

**A. Карточка практики (готовность)**
- Капс: «НАПРАВЛЕНИЕ · ЦЕЛЬ», название, кнопка-иконка «Настроить под себя» (для дыхательных практик) — открывает редактор с копией «<название> — моя».
- «Почему работает»: одна строка и абзац.
- «Противопоказания»: список либо «Особых ограничений нет»; всегда добавляется «Если станет некомфортно — остановись и дыши как обычно».
- Внизу — карточка длительности: число минут, чип «рек.» (вернуть рекомендованное), слайдер min..max; кнопка «Начать · N мин».
- Выбранная длительность запоминается для каждой практики (`durMem`).

**B. Плеер**
- Отсчёт 3-2-1 «Приготовься».
- Орб в цвете цели масштабируется по фазе. В центре — секунды до смены фазы, над орбом — название фазы (Вдох / Задержка / Выдох / Довдох / Задержка на выдохе / Свободное дыхание).
- Нижняя панель (всегда видна): прогресс → один ряд «Голос · Тон · ⏸/▶ · Вибро · ↺ Заново» → ссылка «Закончить и оценить». Кнопки 44 dp без подписей (вкл. — светлая заливка, выкл. — обводка; ↺ всегда в стиле «вкл.»), пауза — белый круг 68 dp. Перемотки нет.
- Пауза — кнопкой или тапом по экрану; в орбе «Пауза». ↺ «Заново» виден всегда: сброс на «Приготовься» и сразу запуск, сессия не пишется. Подробно — `player/README.md`.
- За 3,5 с до смены шага — подсказка «Дальше: …».
- Сегментированный прогресс по шагам; прошло / −осталось; кнопка «Завершить».
- **Практики с шагами** (медитации, визуализации, психотехники, тело): длительность делится поровну между шагами. На экране — номер шага в орбе и текст шага под ним; голос зачитывает текст в начале шага. Орб медленно «дышит» (цикл 10 с), звук дыхания не играет.

**C. «Как теперь?»**
- Заголовок, «Было: ● состояние», для программ — «Пройдено: …».
- Крупное лицо выбранной оценки и подпись к нему:
  - Хуже — «Бывает — попробуем другую практику»
  - Так же — «Это тоже данные»
  - Лучше — «Хорошее начало»
  - Отлично — «Практика сработала»
- Если выбрано **Хуже** или **Так же** — кнопка «Больше не предлагать». После нажатия: «Скрыта из подборок · Вернуть» (см. §5.6).
- Шкала из 4 лиц на pill-подложке с перемещающимся ореолом; подписи снизу.
- Поле «Что заметил? Мысли, ощущения…» (до 280 символов), кнопка «Готово».
- ♥ в шапке — добавить в избранное. ✕ — пропустить оценку (сессия всё равно записывается).

### 3.5 Каталог

- Шапка: «Каталог» и «+» (меню: Своя техника / Своя программа).
- «Избранное» — горизонтальная лента.
- Фильтр-чипы: Все / Фокус / Сон / Спокойствие / Энергия.
- Группы: Инструменты, Мои техники, Программы, Курсы, Практики.
- В группе больше 5 элементов — показываются 4 и «Ещё…» / «Свернуть».
- Пустое избранное: «Отметь практику сердцем — она появится здесь».
- Пустой фильтр: «Здесь пока пусто» · «Выбери «Все» или верни скрытые практики».
- Платные элементы — с замком.
- Внизу, если что-то скрыто, — ссылка «Скрытое · N» (иконка перечёркнутого глаза).

### 3.6 Скрытое

- Заголовок «Скрытое» и пояснение: «Практики и программы, которые ты попросил не предлагать. Вернёшь — снова появятся в Каталоге и подборках».
- Разделы **Практики** и **Программы**; у каждой строки кнопка «Вернуть».
- Пустое состояние: «Ничего не скрыто» · «Все практики и программы снова в подборках».

### 3.7 Программа

- Капс «ПРОГРАММА · ОДНА СЕССИЯ», название, мета; ✎ «Настроить» (встроенная программа → копия «… — моя») или «Изменить».
- Таймлайн шагов (номер, название, длительность).
- «Шаги идут подряд без ручных переходов. За 3 секунды до смены — подсказка «Дальше»».
- Противопоказания — объединение по всем шагам, дубли по смыслу (часть до « — ») убираются.
- Кнопка «Начать».

### 3.8 Редактор программы

Шаги: **техника** или **пауза** (свободное дыхание 15 с – 5 мин). В шаг можно добавить любую встроенную практику или свою технику:
- дыхательная — длительность в минутах или циклах (линейка циклов 1–300);
- практика с шагами (медитация, визуализация, психотехника, тело) — только минуты.

Длительность задаётся слайдером. Порядок меняется кнопкой ↑, шаг можно удалить. Внизу — «Итого», «Попробовать», «Сохранить».

### 3.9 Своя техника (редактор)

- Раунд состоит из блоков; блок — это фазы и число повторов.
- Тап по фазе меняет её тип по кругу: вдох → довдох → задержка → выдох → задержка на выдохе.
- Есть число раундов и отдых между раундами.
- Все значения задаются **слайдерами**, как в редакторе программ:
  - длительность фазы 0,5–120 с, шаг нелинейный: до 10 с — 0,5 с; до 30 с — 1 с; дальше — 5 с;
  - повторы блока 1–60;
  - раунды 1–10;
  - отдых между раундами 0–300 с, шаг 5 с.
- Итого, «Попробовать», «Сохранить»; в меню — Дублировать / Удалить.
- Валидация (`rules`): имя обязательно; хотя бы один блок; блок не пустой; нужен хотя бы один вдох.
- Предупреждение для интенсивных техник не показываем.

### 3.10 Курс

Курс — это дни. В каждом дне — название, практика и минуты. Прогресс по дням показан сегментами.
- Новый день открывается на следующий день после предыдущего. Пропустил — продолжишь с того же места.
- Без Plus открыт только день 1, остальные помечены «Plus».
- После последнего дня: «Курс пройден. Практики остаются в каталоге — возвращайся к тем, что сдвигали сильнее».

### 3.11 Таймер медитации

- «Недавние» — последние конфигурации.
- Длительность: колёса часы (0–5) и минуты (0–59) или «Без конца».
- Ход сессии: Подготовка (тишина перед стартом) → звук Начала → Интервалы → звук Конца.
- Звуки: Чаша, Гонг, Колокольчик, Метроном, Дерево, Вибрация, Нет. Без конца — звук конца «прозвучит при остановке».
- Интервал: «Без повторения» (в момент N) или «Повторять» (каждые N), со своим звуком.
- Сессия таймера: капс «Подготовка / Осталось / Прошло», крупное время (84), «Звук через m:ss» или «Дальше тишина», подсветка в момент звука, пауза, «Завершить».
- **Итог таймера** (показывается, если прошло > 30 с после подготовки; иначе — назад к настройке): иконка медитации в круге 128 dp, «N минут тишины» («Меньше минуты тишины»), мета «Чаша · 2 интервала · 07:15–07:35» (звук начала · интервалы · начало–конец). Ниже две карточки: «Сегодня» (время + «N сессий») и «За неделю» (время за 7 дней + «M дней из 7»); обе включают текущую сессию. Текст «Сессия сохранена. Отметь, как ты сейчас, — увидишь сдвиг.» Кнопки: «Готово» (1/3, вторичная) — сохранить без оценки → Сегодня; «Как теперь?» (2/3, акцент) → оценка. Сессия записывается как «Таймер медитации», `kind = TIMER`. Подробно — `timer-done/README.md`.

### 3.12 Метроном

- Темп 20–240 уд/мин: круговой dial, кнопки −/+ и tap tempo.
- Ритм: доли 1–12, тап по доле меняет её тип (акцент / обычная / пауза). Деление доли: нет / ½ / триоль / ¼.
- Вибрация в такт (сильнее на первой доле).
- «Плавный темп»: менять темп до X за N минут (замедление успокаивает, разгон бодрит). Пресеты: «Успокоиться · 60 → 40» (10 мин), «Ко сну · 50 → 30» (15 мин), «Разогнаться · 70 → 110» (5 мин).
- Звук: Метроном / Дерево / Барабан; громкость; автостоп «Через время» или «Без автостопа».
- «Недавние» — последние конфигурации.
- Сессия: dial с BPM, пульсирующее кольцо, точки долей (акцент — 24 dp, обычная — 18 dp, текущая подсвечена), строка «Темп 60 → 40» или «Дерево · 4/4», время.

Файлы звуков и правила воспроизведения (pitch, громкость акцента) — `sounds/CREDITS.md`.

Аудио метронома должно идти по точному планировщику (look-ahead scheduling), а не через `delay` в корутинах.

### 3.13 Прогресс

- Сводка в шапке: «N сессий · X ч Y мин за всё время».
- **«Время практик»** (перед «Сессиями») — компактная карточка: капс «ВРЕМЯ ПРАКТИК», время за месяц календаря (Nunito 24), «Октябрь · N сессий · по практикам и типам», шеврон. Тап открывает bottom sheet «Время практик»: переключатель периода «<месяц календаря> / Всё время» (месяц меняется стрелками календаря), чипы-фильтр по типу: Все · Дыхание · Медитация · Таймер · Тело · Психотехника · Транс · Программы (показываем только типы с сессиями за период). Карточка: суммарное время (Nunito 30), «N сессий · M дней», список практик по убыванию времени (точка цвета цели, название, «N раз», время, полоса относительно лидера). Первые 5, дальше «Показать все · N». Пусто: «В этом месяце практик пока не было».
- Календарь месяца (стрелки ‹ › по месяцам): в дне с оценкой — лицо лучшей оценки дня, без оценки — точка, иначе число. Подпись месяца: «N дней · легче в X из Y».
- Тап по дню с сессиями — шторка дня со списком и «+ Добавить сессию в этот день»; тап по пустому дню — сразу добавление сессии на этот день.
- **«Что помогает, когда ты…»** — 4 состояния со счётчиками оценённых сессий. Тап по состоянию — топ-3 практики: сортировка по доле сессий «Лучше» и «Отлично», мета «N раз · X% легче». Мало данных — «Пока мало данных для «<состояние>»».
- «Сессии · Последние 10», «+ Добавить». «Все сессии…» — только если сессий больше 10.
- Все сессии: поиск «Поиск по заметкам и практикам», редактирование (до, после, заметка, удаление), добавление сессии задним числом (практика или своя, когда, до, после, заметка — всё необязательно).
- Пусто: «Здесь появится твой прогресс» · «Отметь состояние, сделай практику и оцени, как стало. Через несколько сессий будет видно, что тебе помогает.» · «Отметить состояние».

| bestself | Лучшее возможное «я» | Психотехника | Энергия | 3–10 / 5 | шаги | — |

Тексты «Почему работает» сверены с доказательной базой: без обещаний «включает», «самый быстрый», «главная причина» — только «смещает», «один из», «одна из частых».

**Программы (4)** — смешанные: дыхание + практика с шагами.

| Программа | Цель | Шаги |

| Перед сном | Сон | exhale 3 мин → pmr 5 мин → leaves 5 мин |
| Снять напряжение | Спокойствие | sighs 3 мин → reson 3 мин → metta 5 мин |
| Собраться перед делом | Фокус | sighs 1 мин → box 3 мин → woop 3 мин |
| Утренний запуск | Энергия | activate 2 мин → пауза 30 с → bestself 3 мин |

## 5. Логика

### 5.1 Состояние → квадрант

```
quad(m) = if (m.e >= 0) { if (m.t < 0) CALM_ENERGY else TENSE_ENERGY }
          else          { if (m.t < 0) CALM_TIRED  else TENSE_TIRED  }
```

Время суток: утро / день / вечер — по часам устройства. В прототипе есть принудительный режим для теста.

### 5.2 Цель по умолчанию

| Состояние | Утро / день | Вечер |
|---|---|---|
| В порядке | Фокус | Фокус |
| На взводе | Фокус | Спокойствие |
| В тумане | Энергия | Сон |
| На пределе | Спокойствие | Сон |

Пользователь меняет цель чипами на экране Подбора.

### 5.3 Рекомендация `recommend(quad, goal, tod, minutes)`

`tense` = На взводе или На пределе.

| Цель | Список | Маршрут |
|---|---|---|
| Фокус | tense: box, sighs, onetask, woop · иначе: anchor, box, onetask, woop | «Снизим напряжение, энергию сохраним» / «Удержим ясность» |
| Спокойствие | sighs, reson, ground, name, safe, metta | «Снизим напряжение» |
| Сон | tense: exhale, pmr, scan, descent · иначе: scan, exhale, pmr, leaves, descent | «Сначала выдохнуть, потом вниз — ко сну» / «Мягко вниз — ко сну» |
| Энергия | tense: sighs, move, onetask · иначе: activate, move, onetask, bestself | «Сначала 2 мин успокоения, потом вверх» / «Поднимем энергию» |

Правила:
1. Вечером, если цель не «Энергия», убрать activate / move.
2. Убрать скрытые практики. Если не осталось ничего — взять нескрытые практики этой цели.
3. Сначала практики, у которых минимальная длительность укладывается в доступное время, затем остальные.
4. Первая практика — hero, вторая и третья — «Или».
5. Длительность старта = `recMin` или подходящее значение из диапазона.

**«На сегодня»**: утро — activate, box, anchor; день — sighs, move, onetask; вечер — exhale, leaves, scan. Если задан `prefGoal` — 2 практики этой цели плюс дневной набор, всего 3. Вечером при цели «Сон» (или без цели) первой идёт карточка «Перед сном» (exhale 3 мин). Скрытые исключаются. Без Plus бесплатные идут первыми.

### 5.4 План воспроизведения `buildPlan(steps)`

- Шаг превращается в слоты фаз. Техника: фазы × циклы (циклы = минуты × 60 / длина цикла либо заданное число). Пауза — один слот «Свободное дыхание».
- У слота есть начало, длительность, тип фазы, номер шага, раунд.
- Плеер считает `elapsed` (от −3 для отсчёта), находит текущий слот, масштаб орба и подписи.
- Подсказка «Дальше: <следующий шаг>» — когда до конца шага меньше 3,5 с.
- Звуки и голос — на границах слотов, с учётом настроек голоса, тона, вибрации и звука дыхания.

В Compose плеер — `StateFlow<PlayerState>`, тикает от монотонных часов (`withFrameNanos` / `TimeSource.Monotonic`), а не от счётчика задержек.

### 5.5 Оценка «Как теперь?»

```
options = [Хуже d=-1, Так же d=0, Лучше d=0.5, Отлично d=1]
after.e = clamp(before.e + 0.3 * d)
after.t = clamp(before.t - 0.45 * d)
```

Если `before` не отмечено, берётся `Mood(0, 0.3)`. По умолчанию выбрано «Так же».

Категория сдвига в Прогрессе (если нет явной оценки `rating`):

```
v = (before.t - after.t) + max(0, after.e - before.e) * 0.6
v > .55 → Заметно лучше; v > .2 → Немного лучше; v > -.1 → Без изменений; иначе → Хуже
```

«Стало легче» = оценка ≥ «Немного лучше».

### 5.6 Скрытие практик и программ

- Где скрыть: «Как теперь?» при оценке Хуже или Так же → «Больше не предлагать». Работает для встроенных практик и для программ (своих техник это не касается).
- Сразу после скрытия — «Скрыта из подборок · Вернуть» (отмена на месте).
- Скрытое не показывается в: Каталоге, «Избранном», Подборе (hero и альтернативы), «На сегодня», списках программ.
- Скрытое остаётся в: истории сессий, курсах (день курса нельзя пропустить молча), своих программах как шаг.
- Где вернуть: Каталог → внизу «Скрытое · N» → экран «Скрытое» → «Вернуть».
- Хранить в `Prefs.hidden` (persist; синхронизация с аккаунтом).

### 5.7 Избранное

♥ в плеере и на «Как теперь?» — добавить или убрать. По умолчанию в избранном: sighs, exhale. Показывается лентой вверху Каталога.

### 5.8 Длительность

- Слайдер в пределах min..max практики; чип «рек.» возвращает к рекомендованному.
- Последний выбор запоминается для каждой практики (`durMemory`).
- В программе для техники можно задать минуты или циклы.

### 5.9 Сессии и история

- Сессия записывается при «Готово», при пропуске оценки (`after = null`) и после таймера.
- Поля: практика или программа, название, до, после, оценка, заметка, время, **длительность**.
- Длительность = фактически проведённое время: практика/программа — проигранное время без отсчёта «Приготовься» и пауз (при досрочном выходе — до момента выхода); таймер — прошедшее время без «Подготовки».
- В строке сессии: «Сегодня, 15:40 · 5 мин · На взводе → лучше». Формат: < 60 с — «N с», дальше «N мин», «N ч M мин».
- В «Новой сессии» и редактировании — блок «Длительность» (− / + по 1 минуте). По умолчанию для новой — рекомендованная длительность выбранной практики, иначе 5 мин; 0 = «Не указано».
- Сессии можно редактировать и добавлять вручную задним числом.

## 9. Paywall (Shift Plus)

**Бесплатно**
- По 2 практики на состояние: В порядке — Квадратное дыхание, Якорь · На взводе — Циклические вздохи, Заземление · В тумане — Микро-движение, Первый шаг · На пределе — Удлинённый выдох, Назвать эмоцию. Плюс Листья на ручье и Лучшее возможное «я».
- День 1 каждого курса.
- 2 готовые программы: «Перед сном», «Снять напряжение».
- 1 своя техника, 1 своя программа. Таймер, метроном, история.
- **Первая неделя после установки — всё открыто**: без замков. В карточке Shift Plus в Настройках — «Первая неделя — всё открыто · ещё N дней». По окончании один раз показывается paywall с причиной «Первая неделя позади…», затем появляются замки.

**Shift Plus:** вся библиотека практик, остальные готовые программы, свои техники и программы без лимита.

**Когда показываем**
- Один раз по окончании первой недели.
- Из Настроек (карточка Shift Plus).
- Создание 2-й своей техники (новая, копия, «сделать свою») или 2-й своей программы (включая «Настроить» готовую).
- Нажатие на платную практику, программу или закрытый день курса.

Подзаголовок по причине: практика — ««<название>» — в Shift Plus. Часть практик для каждой цели открыта бесплатно.» · программа — «… Свою программу можно собрать и бесплатно.» · своя техника — «Бесплатно — одна своя техника. С Plus их может быть сколько угодно.» · своя программа — «Бесплатно — одна своя программа. Платные карточки помечены замком. В подборе для бесплатных пользователей бесплатные практики идут первыми.

**Управление подпиской (упрощённо)**
- В Настройках — карточка Shift Plus: без подписки ведёт в paywall, с подпиской открывает шторку статуса.
- Шторка: тариф, статус (Активна / Отменена), «Следующее списание» или «Доступ до». Отменённая — «Подписка отменена и не продлится. Возобновить её можно в <магазин>».

  - iOS: системный экран `showManageSubscriptions` прямо в приложении.
- «Восстановить покупки» на paywall обязательна (требование App Store).
- Статус подписки берётся из магазина: Google Play Billing (активная покупка, `isAutoRenewing`) и StoreKit 2 (`Transaction.currentEntitlements`, `renewalInfo.willAutoRenew`, `expirationDate`).
- Биллинг: нативный, через expect/actual — Google Play Billing Library (Android) и StoreKit 2 (iOS), без RevenueCat; право доступа `plus`.

## 10. Отложено

| Что | Решение сейчас | Когда вернуться |
|---|---|---|
| Синхронизация | Данные на устройстве + системная резервная копия; без своего сервера | Веб-версия, обмен программами, много пользователей с двумя устройствами |
