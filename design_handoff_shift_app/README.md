# Handoff: Shift — приложение для смены состояния (iOS + Android)

## Overview
Shift — короткий цикл «отметил состояние → короткая практика → «Как теперь?» → видишь сдвиг». В пакете: интерактивный прототип всех экранов, полная спецификация дизайна и логики, готовая тема для Compose.

## About the Design Files
Файлы в пакете — **дизайн-референсы в HTML**: прототип показывает задуманный вид и поведение, это не продакшн-код. Задача — **воссоздать дизайн в целевом стеке** (Compose Multiplatform + Material 3, см. `spec.md` §8) по его принятым паттернам, а не переносить HTML.

## Fidelity
**High-fidelity.** Цвета, типографика, отступы, тексты и взаимодействия — финальные. Воспроизводить точно.

## Files
- `spec.md` — **главный документ**: дизайн-система (цвета, шрифты, формы, движение), все экраны, модели данных, встроенный контент, алгоритмы (подбор, план воспроизведения, оценка, скрытие), paywall, отложенное. Начинать с него.
- `compose/ShiftColors.kt` — готовая тема: M3 `LightScheme` / `DarkScheme` + `ShiftColors` через `LocalShiftColors`.
- `compose/android/res/` — **иконка и splash для Android**: adaptive icon (background / foreground / monochrome), `splash_icon` (светлая и night), цвета и тема `Theme.Shift.Starting`. Скопировать в `androidApp/src/main/res/`, в манифесте у Activity — `android:theme="@style/Theme.Shift.Starting"`, зависимость `androidx.core:core-splashscreen`.
- `compose/icon-png/` — **iOS и магазины**: AppIcon 1024 (Any / Dark / Tinted) для `Assets.xcassets`, иконка 512 для Google Play Console, знак iOS Launch Screen @3x (светлый и тёмный; фон Launch Screen — color asset `#F5F4FE` / `#141416`).
- `compose/ShiftIcons.kt` — `ShiftIcons.Meditation` (контур в позе лотоса) вместо `ph-timer` везде: «Посидеть в тишине», «Таймер медитации», карточка «Таймер». То же как `android/res/drawable/ic_meditation.xml` и `icon-svg/meditation.svg`. Остальные иконки — Phosphor regular.
- `compose/ShiftSplash.kt` — `ShiftSplashOverlay`: анимация после системного splash (кольца → орб → растворение), общая для Android и iOS. Геометрия и цвета знака — `spec.md` §2.8, логика запуска — §3.0.
- `prototype/Shift v10 Android.dc.html` — прототип. Открыть в браузере (рядом должен лежать `support.js`). Переключатель iOS / Android, тема, состояния — в самом прототипе. Константы (цвета `LIGHT`/`DARK`, контент практик, `recommend()`, `buildPlan()`) — в блоке `<script>` внизу файла; **прототип — источник истины**: при расхождении со `spec.md` верен прототип. В списке экранов — «Запуск — первый раз» (splash → онбординг) и «Запуск — повторный» (splash → Сегодня).
- `prototype/Shift - иконка и splash.dc.html` — иконка во всех вариантах (iOS, Android, themed, тёмная, мелкие размеры) и анимация splash. **Выбран вариант 3b**; остальные — для истории. Рядом должен лежать `ShiftIcon.dc.html`.
- `sounds/` — все звуки: Чаша, Гонг, Колокольчик, Метроном, Дерево, Барабан (записи CC0 / Public domain), тоны интерфейса (отсчёт, старт, смена фазы). Звук дыхания больше не используется. Лицензии, где какой звучит и как воспроизводить — `sounds/CREDITS.md`.

## Assets
- Шрифты: Nunito (600/700/800), Nunito Sans (400–800) — Google Fonts, подключить через `compose.resources`.
- Иконки: Phosphor Icons (regular + fill) — взять из `phosphor-icons` для Compose или экспортировать нужные SVG в `ImageVector`.
- Лица оценки, орб, декоративные формы — рисуются кодом (`Canvas`), пути — в прототипе.
- Иконка приложения и знак splash — готовые файлы в `compose/android/res/` и `compose/icon-png/` (см. выше).

## Как работать с Claude Code
1. Положи папку в репозиторий (например, `docs/design/`).
2. Первый запрос: «Прочитай `docs/design/README.md` и `spec.md`. Составь план реализации по экранам, не пиши код».
3. Дальше по одному слою: тема → иконка и splash (`spec.md` §2.8, §3.0) → компоненты (`spec.md` §2.5) → домен и данные (§4–5) → экраны по одному.
4. Для каждого экрана: «Реализуй экран X по `spec.md` §3.N; сверяйся с прототипом — найди его разметку по `data-screen-label="X"`».
5. Сохрани в `CLAUDE.md` репозитория правило: «Дизайн — `docs/design/spec.md`; при сомнениях смотри прототип».
